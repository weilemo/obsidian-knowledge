# Codex App Features
## 一句话摘要
Codex App 支持多项目并行、技能与自动化、工作树/终端/审核等完整工程工作流。

## 核心功能
- 多项目并行处理与多线程管理
- Skills 与 Automations
- Local/Worktree/Cloud 运行模式
- 内置 Git 工具与 Review 面板
- Worktree 支持与内置终端
- 语音输入、IDE 同步
- MCP 服务器支持与 Web 搜索
- 安全沙箱与权限审批

## 使用步骤
- 选择项目并进入线程
- 依据需求选择运行模式（Local/Worktree/Cloud）
- 使用技能或自动化提高重复任务效率
- 通过 Review 面板审阅与采纳改动

## 适用场景
- 同时推进多个仓库/项目
- 需要稳定、安全的本地执行环境
- 需要自动化/批量化任务

## 注意事项
- 运行模式决定任务在哪里执行（本地/工作树/云端）
- 沙箱与权限审批会限制高风险操作
