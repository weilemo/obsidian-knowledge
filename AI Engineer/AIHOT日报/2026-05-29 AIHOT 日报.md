## 论文研究

### SIA：AI 智能体递归自我改进框架

hexoai 开源 SIA 框架，展示智能体不仅可以优化外部工作流，还可以通过任务反馈更新自身模型权重。论文报告称，SIA 在 LawBench、GPU kernels 和单细胞 RNA 去噪任务中取得明显提升。

来源：[Rohan Paul](https://x.com/rohanpaul_ai/status/2060063592448446778)

### SGLang 与 AMD 优化 DeepSeek-R1 分离式推理

SGLang 与 AMD 团队通过 MoRI 混合 FP4/FP8 通信、MoRI-IO KV Cache 后端、两批重叠、ROCm Specv2 MTP 等全栈优化，使 AMD MI355X 在 DeepSeek-R1 大规模推理中取得有竞争力的 TCO。

来源：[LMSYS Blog](https://www.lmsys.org/blog/2026-05-28-mori)

## 技巧与观点

### NVIDIA Polar：面向智能体的强化学习框架

NVIDIA 研究团队开源智能体强化学习框架 Polar。该框架无需重写 Codex CLI、Claude Code、Qwen Code、Pi 等执行框架，而是在模型 API 边界接入 GRPO 训练。实验中，基于 Qwen3.5-4B，Polar 将 Codex 在 SWE-Bench Verified 的 pass@1 从 3.8% 提升到 26.4%。

### Tunix + TPU：社区后训练 Gemma 学会推理

Google 介绍 Kaggle Tunix 黑客马拉松中，社区如何用 TPU 和有限算力将小型基础模型转成通用推理引擎。获胜流程结合 SFT、GRPO、SimPO 等后训练技术。

来源：[Google Developers Blog](https://developers.googleblog.com/how-the-community-trained-gemma-to-think-with-tunix-and-tpus)

### Adam's Law：高频表达可能提升 Prompt 效果

FaceMind 团队提出文本频率定律：语义不变时，使用预训练语料中更高频的表达写 prompt 或做微调，可能提升大语言模型表现。

来源：[Berry Xia](https://x.com/berryxia/status/2060212428584202428)
