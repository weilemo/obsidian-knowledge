# 2026-06-03 AIHOT 日报

## 今日重点

今天最值得关注的是微软自研推理模型 MAI-Thinking-1、Claude Code 动态工作流、OpenAI Codex Python SDK、GitHub Copilot 桌面应用，以及 Anthropic 可解释性与安全产品线扩展。这几条分别对应模型自研、coding agent、agent workflow、知识工作自动化与 AI 安全。

## 模型发布/更新

### 微软首款高级推理 AI 模型 MAI-Thinking-1 发布

微软在 Build 2026 上发布首款高级推理 AI 模型 MAI-Thinking-1。该模型被定位为中等规模，在关键软件工程基准测试中达到领先模型水平。微软称其完全从头使用干净数据训练，没有从第三方模型蒸馏知识。

来源：[The Verge](https://www.theverge.com/tech/941664/microsoft-ai-model-reasoning-mai-thinking-1-build-2026)

### Holo3.1：快速本地计算机使用智能体

Holo3.1 是基于 Qwen 模型家族的计算机使用智能体系列，面向桌面、网页与移动环境。新模型覆盖 0.8B、4B、9B 和 35B-A3B 多种尺寸，并发布 FP8、Q4 GGUF、NVFP4 等量化检查点。在 AndroidWorld 基准上，35B-A3B 得分从 67% 提升到 79.3%。

来源：[Hugging Face Blog](https://huggingface.co/blog/Hcompany/holo31)

### 阶跃星辰 Step 3.7 Flash 发布，专为高效推理设计

阶跃星辰发布推理优化模型 Step 3.7 Flash。该模型采用 196B MoE 架构，重点优化推理效率；其多矩阵分解注意力机制将 KV-cache 成本降到 DeepSeek 模型约 22%，并通过注意力与 FFN 解耦提升硬件服务效率。模型已通过 Fireworks AI 提供，采用 Apache 2.0 许可。

来源：[StepFun](https://x.com/StepFun_ai/status/2061655529731342402)

## 产品发布/更新

### Claude Code 新增动态工作流功能

Claude Code 新增动态工作流功能，允许模型在运行时创建和协调多智能体框架来处理复杂任务。该机制通过执行特定 JavaScript 文件来生成拥有独立上下文窗口的子代理，适合研究、安全分析、代码审查等高价值复杂任务。

来源：[Claude Blog](https://claude.com/blog/a-harness-for-every-task-dynamic-workflows-in-claude-code)

### Claude Platform 新增 CLI 工具

Claude Platform 新增 CLI 工具，使 API 端点可以从终端运行，包括调用 Messages API、启动 Claude 托管智能体，并将结果直接管道传输到 shell。该工具也适合被 Claude Code 等编码智能体调用。

来源：[Claude Devs](https://x.com/ClaudeDevs/status/2061877343078244459)

### OpenAI Codex 发布 Python SDK，可直接嵌入应用

OpenAI Codex 发布 Python SDK，可通过 `pip install openai-codex` 安装并集成到应用代码中。该 SDK 的关键点是可以复用 Codex 登录态，让开发者把 Codex 编程能力嵌入自己的工具链。

来源：[Vista](https://x.com/vista8/status/2061846741885018296)

### Google DeepMind 开源科学智能体工具包

Google DeepMind 开源 Science Skills，这是面向科学发现自主智能体的专用工具包，强调科学基础能力与更高 token 效率，已在 GitHub 发布。

来源：[Google AI for Developers](https://x.com/googleaidevs/status/2061924472245153863)

### 微软开源 Adaptive Spec-driven Scoring

微软开源 Adaptive Spec-driven Scoring for Evaluation and Regression Testing 框架。开发者可用文本描述生成 AI 行为测试，用于模型评估与回归测试。

来源：[TechCrunch](https://techcrunch.com/2026/06/02/new-microsoft-tool-lets-devs-spin-up-ai-behavior-tests-using-text-descriptions)

### Runway API 推出 Aleph 2.0 视频编辑功能

Runway API 新增 Aleph 2.0，可将精准视频编辑集成到应用、产品和平台中，支持最长 30 秒、1080p、多镜头序列的视频编辑。

来源：[Runway](https://x.com/runwayml/status/2061895998545244342)

### GitHub Copilot 应用：智能体原生的桌面体验

GitHub 在微软 Build 2026 上发布新的 Copilot 应用，定位为智能体原生的桌面体验，目标是让 AI 智能体以用户熟悉的桌面方式工作。

Replit 与 Microsoft 合作，支持组织在 Replit 中构建内部工具、工作流或数据仪表板，并直接发布到 Microsoft Fabric，同时内置安全、身份验证与治理能力。
