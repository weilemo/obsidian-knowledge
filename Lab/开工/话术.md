## 文档更新规则

最简单的规则是：

- 有长期稳定事实更新，就改 `MEMORY.md`
- 有当前任务进展更新，就改 `STATUS.md`
- 要换 agent 接手，就改 `HANDOFF.md`
- 有关键技术决策落地，就改 `DECISIONS.md`
- 有一次完整任务过程，就在 `logs/` 新建一条日志，参考 `TASK_TEMPLATE.md`

可以按这个节奏用：

1. 任务开始前  
   把“这次要干什么”写到 `STATUS.md` 的“当前目标”和“正在做什么”。

2. 任务进行中  
   如果只是试了哪些命令、跑了哪个作业、报了什么错，不要塞进 `MEMORY.md`，先记到任务日志里。

3. 任务结束后  
   更新 `STATUS.md` 的“最近完成”“当前阻塞”“下一步”，然后在 `logs/` 补一条记录。

4. 如果沉淀出长期信息  
   比如“训练统一用哪个环境”“常用数据路径在哪”“主脚本是哪个”，再补到 `MEMORY.md`。

5. 如果要交给另一个 agent  
   把“现在做到哪、卡在哪、下一个人先干什么”压缩写到 `HANDOFF.md`。

一句话：

- `STATUS.md` 管“现在”
- `MEMORY.md` 管“长期”
- `HANDOFF.md` 管“立刻接手”
- `DECISIONS.md` 管“以后别反复改”
- `logs/` 管“这次具体做了什么”
