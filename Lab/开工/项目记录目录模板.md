# 项目记录目录模板

把下面这套文件放到“具体项目目录”下，而不是服务器根目录：

```text
项目目录/
├── README.md
├── MEMORY.md
├── STATUS.md
├── HANDOFF.md
├── DECISIONS.md
├── TASK_TEMPLATE.md
└── logs/
    └── README.md
```

## 每个文件的职责

- `README.md`：说明这套记录怎么用，agent 怎么接力
- `MEMORY.md`：长期稳定事实
- `STATUS.md`：当前状态
- `HANDOFF.md`：agent 快速交接
- `DECISIONS.md`：关键技术决策
- `TASK_TEMPLATE.md`：单次任务日志模板
- `logs/`：单次任务日志目录

## 最小维护规则

- 长期事实不要写进 `STATUS.md`
- 当前状态不要堆进 `MEMORY.md`
- 单次训练、调试、排障、Slurm 作业，统一写到 `logs/`
- 切换 agent 前，先更新 `HANDOFF.md`

## 推荐起手顺序

1. 先复制整套模板到目标项目目录
2. 按项目实际情况填写 `MEMORY.md`
3. 用 `STATUS.md` 维护当前任务
4. 每次任务后在 `logs/` 新增记录
