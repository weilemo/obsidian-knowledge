# Codex App Commands
## 一句话摘要
汇总 Codex App 的常用快捷键与 / 命令入口。

## 核心功能
- Command menu 与 / 命令
- 线程与界面导航
- 终端与 diff 面板控制
- 语音输入

## 使用步骤
- 打开 Command menu：Cmd+Shift+P 或 Cmd+K
- 使用 / 命令：输入 `/` 选择命令
- 启动语音输入：Ctrl+M

## 适用场景
- 需要高频操作或快捷导航
- 快速执行内置命令

## 注意事项
- 部分快捷键仅在 macOS 可用
- / 命令列表会展示已启用的技能
