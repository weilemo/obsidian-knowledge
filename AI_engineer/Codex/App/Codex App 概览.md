# Codex App 概览
## 一句话摘要
Codex App 是桌面端“指挥中心”，支持并行线程、Git worktree、自动化与内置 Git 能力。

## 核心功能
- 桌面端并行处理 Codex 线程
- 内置 Git、worktree 与自动化能力
- 作为 Codex 的统一入口与项目管理界面

## 使用步骤
- 下载并安装 macOS 版 Codex App
- 使用 ChatGPT 账号或 OpenAI API Key 登录
- 选择本地项目目录
- 在 Local 模式下发送首条消息

## 适用场景
- 希望在桌面端集中管理多个项目
- 需要结合 Git / worktree 的 Codex 工作流

## 注意事项
- 当前仅支持 macOS（Apple Silicon）
- 使用 API Key 登录时，部分功能（如 Cloud 线程）可能不可用
