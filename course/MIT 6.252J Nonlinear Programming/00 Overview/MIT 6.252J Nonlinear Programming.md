# MIT 6.252J Nonlinear Programming

Source: [MIT OpenCourseWare 6.252J Nonlinear Programming](https://ocw.mit.edu/courses/6-252j-nonlinear-programming-spring-2003/)

## Course Info

- University: MIT
- Course: 6.252J / 15.084J Nonlinear Programming
- Term: Spring 2003
- Level: Graduate
- Instructor: Dimitri P. Bertsekas
- Main text: Dimitri Bertsekas, *Nonlinear Programming*, 2nd ed., Athena Scientific, 1999.

## Core Themes

- Unconstrained optimization methods
- Constrained optimization methods
- Convex analysis
- Optimality conditions
- Lagrange multiplier theory
- Duality theory
- Lagrangian relaxation
- Nondifferentiable optimization
- Applications in integer programming, control, communications, power systems, and resource allocation

## Relation to MATH3306P Optimisation

This course is a stronger and more classical reference for the nonlinear programming part of MATH3306P:

- MATH3306P: gradient, Newton/quasi-Newton, KKT, simplex, penalty methods.
- MIT 6.252J: gradient, Newton/Gauss-Newton, feasible directions, projection, Lagrange multipliers, inequality constraints, duality, interior point, penalty and augmented Lagrangian methods.

The main missing piece compared with MATH3306P is the simplex algorithm for linear programming, which can be supplemented by MIT 15.093J Optimization Methods.
