# MIT 18.06SC Linear Algebra

Source: [MIT OpenCourseWare 18.06SC Linear Algebra](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/)

## Course Info

- University: MIT
- Course: 18.06SC Linear Algebra
- Term: Fall 2011
- Level: Undergraduate
- Instructor: Prof. Gilbert Strang
- Department: Mathematics
- Topic: Linear Algebra
- Format: Independent study course with lecture videos, summary notes, readings, problem-solving videos, problem sets, exams, and selected demonstrations.
- Main text: Gilbert Strang, *Introduction to Linear Algebra*.

## Core Themes

- Matrix theory and systems of linear equations
- Elimination, matrix multiplication, inverses, and LU factorization
- Vector spaces, column space, nullspace, basis, dimension, and rank
- The four fundamental subspaces
- Orthogonality, projections, least squares, and Gram-Schmidt
- Determinants, eigenvalues, eigenvectors, diagonalization, and matrix powers
- Symmetric and positive definite matrices
- Complex matrices, FFT, SVD, linear transformations, change of basis, and pseudoinverse

## Study Strategy

This course is best treated as a concept-first linear algebra spine:

1. Watch the lecture video and skim the summary notes.
2. Rewrite the key definitions and formulas in your own notation.
3. Do the problem set before looking at solutions.
4. Use exam reviews as checkpoints after each unit.
5. Build small computational examples in Python or MATLAB-style notebooks for topics like projections, eigendecomposition, SVD, and image compression.
