# Tools

## Recommended Computational Tools

- Python: NumPy, SciPy, Matplotlib.
- Jupyter notebooks for numerical experiments.
- MATLAB or Octave for following some original MIT demonstrations.

## Experiment Ideas

- Visualize row operations as left multiplication by elimination matrices.
- Compare classical Gram-Schmidt and modified Gram-Schmidt.
- Implement least squares by normal equations and by QR decomposition.
- Compress an image using truncated SVD.
- Simulate Markov chains using eigenvalues and steady states.

## Formula Conventions

Use LaTeX for all formulas. Prefer block formulas for derivations:

$$
A = U \Sigma V^T
$$
