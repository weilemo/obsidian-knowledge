# CS61A 课程主题与版本选择

## 推荐策略

自学时采用稳妥策略：

1. 当前 `cs61a.org` 作为入口。
2. `Composing Programs` 作为长期稳定教材。
3. 如果当前学期作业或链接受限，就选一个公开归档学期作为 lab / homework / project 主线。

## 主题地图

| 模块 | CS61A 关键词 | 应该掌握到什么程度 |
|---|---|---|
| Python basics | expression、statement、function | 能读写小程序 |
| Environment | frame、binding、scope、call expression | 能画环境图 |
| Recursion | base case、recursive case、tree recursion | 能解释递归执行 |
| Higher-order functions | function as value、lambda、decorator intuition | 能把重复逻辑抽象成函数 |
| Data abstraction | constructor、selector、abstraction barrier | 能分离接口和表示 |
| OOP | class、method、inheritance、dispatch | 能读写简单对象模型 |
| Scheme | list、special form、lambda、tail recursion | 能写基本 Scheme 程序 |
| Interpreter | eval、apply、special forms | 能解释解释器主循环 |
| SQL | select、join、aggregation | 能写基础查询 |

## 与 CS61B 的衔接

| CS61A 模块 | 到 CS61B 的迁移 |
|---|---|
| Environment diagrams | Java reference / object memory model |
| Recursion | Tree / graph traversal |
| Data abstraction | ADT / interface / implementation |
| OOP | Java classes and inheritance |
| Interpreter project | 中型项目拆解、测试和模块边界 |
