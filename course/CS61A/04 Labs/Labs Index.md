# Labs Index

## Lab 记录模板

每个 lab 建议记录：

- 目标：这个 lab 想训练什么。
- 关键函数：每个函数的输入、输出、边界情况。
- 实现步骤：先写 base case / simple case，再扩展。
- 测试：跑了哪些 doctest / ok test。
- 卡点：是语法、递归、环境图还是抽象问题。
- 复盘：这次学到的思考方式。
