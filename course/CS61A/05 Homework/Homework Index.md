## 重点题型

| 题型 | 训练内容 |
|---|---|
| Environment diagrams | 求值过程 |
| Recursion | base case / recursive case |
| Tree recursion | 分支结构和组合结果 |
| Higher-order function | 抽象重复逻辑 |
| Scheme | 语法和递归 |
| Interpreter | eval / apply |
