# CS61A Structure and Interpretation of Computer Programs

## 从这里开始

1. 先读 `00 Overview/CS61A 学习总览.md`。
2. 再按 `00 Overview/暑假 6 周学习路径.md` 执行。
3. 第一天照 `00 Overview/启动清单.md` 配环境。
4. 代码路径和 repo 状态记录在 `08 Code/README.md`。

## 当前学习主线

- 当前官方入口：<https://cs61a.org/>
- 教材：<https://www.composingprograms.com/>
- 公开历史资料入口：<https://cs61a.org/articles/about/>
- 代码工具：Python、OK / pytest、Scheme interpreter project。

## 第一阶段目标

暑假前半段先追求：

- Python 基础、递归、环境图能讲清楚。
- Hog / Cats 至少完成一个并写复盘。
- Higher-order function、tree recursion、Scheme 有可翻的模块笔记。
- 每个项目记录一次“抽象怎么帮我减少 bug”。
