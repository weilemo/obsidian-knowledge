# Projects Index

## 项目原则

CS61A 的项目训练的是抽象、递归、测试和拆解。做项目时重点记录：

1. specification 如何映射到函数。
2. 哪些地方需要递归或高阶函数。
3. 数据表示和抽象边界。
4. 测试如何暴露错误理解。
