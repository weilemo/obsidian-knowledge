# CS61A Local Memory

## 工作区定位

本文件夹是暑假自学 UC Berkeley CS61A Structure and Interpretation of Computer Programs 的 Obsidian 工作区。

## 默认策略

- 当前 `cs61a.org` 作为入口。
- `Composing Programs` 作为稳定教材。
- 若当前学期作业或链接受限，选一个公开归档学期作为 lab / homework / project 主线。
- 笔记优先围绕求值规则、环境图、递归、抽象边界和项目复盘，而不是逐字转录 lecture。

## 输出习惯

- 新增讲义放在 `03 Lecture Notes`。
- 模块化概念笔记放在 `02 Units`。
- Lab 记录放在 `04 Labs`。
- Homework 记录放在 `05 Homework`。
- Project 记录和复盘放在 `06 Projects`。
- 代码路径记录在 `08 Code/README.md`。
