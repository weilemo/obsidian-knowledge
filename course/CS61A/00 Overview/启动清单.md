# CS61A 启动清单

## 第一小时

- [ ] 打开课程入口 <https://cs61a.org/>。
- [ ] 打开教材 <https://www.composingprograms.com/>。
- [ ] 确认 Python 可用。
- [ ] 建立本地代码目录。
- [ ] 记录本学期或归档学期的 lab / homework / project 链接。

## 第一周结束前

- [ ] 跑通一个 Python lab。
- [ ] 会画简单函数调用的 environment diagram。
- [ ] 写完 `Python 与环境图.md`。
- [ ] 记录 3 个递归或函数调用卡点。

## 第一个项目结束前

- [ ] 项目 specification 已读完。
- [ ] 每个核心函数知道输入、输出和边界情况。
- [ ] 跑过提供的测试。
- [ ] 写项目复盘：抽象、递归、bug、测试。

## 本课程不要这样学

- 不要只把它当 Python 语法课。
- 不要跳过 environment diagram。
- 不要递归题只背答案，要解释 base case 和 recursive case。
- 不要做完项目不复盘，CS61A 最值钱的是抽象和拆解方式。
