# CS61A 暑假 6 周学习路径

## 使用方式

这份路线按“暑假先打牢抽象和递归”的节奏设计。CS61A 不适合只看视频，需要边写代码边画环境图、边复盘递归。

默认资源：

- 课程入口：<https://cs61a.org/>
- 教材：<https://www.composingprograms.com/>
- Staff GitHub：<https://github.com/Cal-CS-61A-Staff>

## Week 0：环境准备

目标：让 Python、课程工具和本地代码目录能跑起来。

要做：

1. 确认 Python 版本。
2. 准备编辑器或 IDE。
3. 建立本地代码目录。
4. 下载或记录一个可用学期的 lab / homework / project 链接。
5. 跑通第一个 lab 或 doctest。

产出：

- `08 Code/README.md`
- `02 Units/Python 环境与工具链.md`

## Week 1：Python 与环境图

目标：能解释函数调用发生了什么。

主题：

- expression / statement
- function definition / call expression
- local frame / global frame
- name binding
- environment diagram
- control flow

练习：

- Python basics lab
- environment diagram discussion

产出：

- `02 Units/Python 与环境图.md`

## Week 2：递归与高阶函数

目标：把递归从“玄学”变成固定思考流程。

主题：

- base case
- recursive case
- mutual recursion
- tree recursion
- higher-order function
- lambda

练习：

- recursion homework
- Hog project 启动或完成

产出：

- `02 Units/Recursion 与 Tree Recursion.md`
- `06 Projects/Hog 项目复盘.md`

## Week 3：数据抽象与 OOP

目标：理解 abstraction barrier，而不是只会写 class。

主题：

- data abstraction
- representation independence
- constructor / selector
- class / object
- inheritance
- method dispatch

练习：

- Cats 或 Ants project
- OOP lab / homework

产出：

- `02 Units/Data Abstraction 与 OOP.md`
- `06 Projects/Cats 或 Ants 项目记录.md`

## Week 4：Scheme

目标：能读写 Scheme，并理解它为什么适合讲解释器。

主题：

- prefix notation
- pairs / lists
- recursion in Scheme
- higher-order functions
- special forms
- tail recursion

练习：

- Scheme lab / homework
- Scheme project 启动

产出：

- `02 Units/Scheme 速查.md`

## Week 5：Interpreter / SQL / Review

目标：把 CS61A 的主线收束成“语言如何被解释”。

主题：

- eval / apply
- interpreter structure
- special form handling
- SQL basics
- final review

练习：

- Scheme project 完成或精读
- 做一套 past exam / review worksheet

产出：

- `06 Projects/Scheme Interpreter 复盘.md`
- `09 Exams/Final Review Packet.md`
