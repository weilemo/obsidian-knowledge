# Exams Index

## 用法

CS61A past exams 很适合检查环境图、递归、Scheme 和解释器理解。自学时不用一开始就刷题，建议学完对应模块后做 topic 题。

## 推荐复习顺序

1. Environment diagrams。
2. Recursion / tree recursion。
3. Higher-order functions。
4. OOP。
5. Scheme。
6. Interpreters。
