# Agent Rules for Course

## 解题说明规范
1. 任何用到的公式，必须先说明来源或给出推导。
2. 不默认用户已知某个公式、定理或技巧。
3. 若使用“已知公式”，需补充：
   - 公式成立条件；
   - 该题中为什么可以使用；
   - 至少一种简要推导或直观解释。
4. 涉及概率/统计中的几何体积法、隔板法、顺序统计量等概念时，先给直观解释，再给数学表达。

## 笔记写作规范
1. 当用户要求“写笔记”时，默认写成独立笔记文件。
2. 不将新内容混入已有笔记，除非用户明确要求“更新原笔记”。
3. 当用户要求“写总结笔记”时，默认产出两份笔记：
   - 一份“考试复习版笔记”：强调高频考点、核心公式、常见题型、易错点，适合考前快速复习；
   - 一份“讲义版笔记”：要求覆盖课件主要内容，按授课逻辑展开，包含概念动机、直觉解释、公式推导、典型例题与知识衔接，目标是尽量做到只看讲义版也能完成系统学习。
4. 若已存在考试复习版笔记，则默认保留原文件，不覆盖；讲义版单独新建或单独更新，避免混淆用途。
5. 数学、概率统计相关笔记中的公式一律使用 LaTeX 语法书写，优先使用块级公式 `$$...$$`，行内公式使用 `$...$`。
