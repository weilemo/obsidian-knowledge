# CS285 核心模块总览

## 模块地图

| 模块 | 核心问题 | 需要的 CS234 基础 | 与当前研究的连接 |
|---|---|---|---|
| Imitation Learning | 能不能直接模仿专家？ | MDP、policy | agent 轨迹蒸馏、SFT |
| Policy Gradient | 如何直接优化策略？ | return、log-derivative trick | RLHF、RLVR、reasoning policy |
| Actor-Critic | 如何降低 policy gradient 方差？ | value、advantage、TD error | critic / reward shaping |
| Q-Learning | 如何学习动作价值？ | Bellman optimality、TD | DQN、decision scoring |
| Offline RL | 能否只用已有数据训练？ | off-policy、distribution shift | agent traces、SWE-bench trajectories |
| Model-Based RL | 能否学环境模型再规划？ | transition dynamics、planning | world model、video dynamics |
| Advanced Topics | 研究前沿 | 以上全部 | LLM agent、memory、control |

## 建议学习顺序

1. Imitation Learning
2. Policy Gradient
3. Actor-Critic 与 PPO
4. Q-Learning 与 Offline RL
5. Model-Based RL 与 World Model
6. Advanced Topics

## 每个模块的笔记模板

每学一个模块，固定回答 6 个问题：

1. 这个模块解决什么问题？
2. 它依赖哪个 Bellman / policy gradient / TD 公式？
3. 算法输入和输出是什么？
4. loss 是什么？
5. 它为什么会失败？
6. 它如何迁移到 LLM / coding agent / memory / world model？
