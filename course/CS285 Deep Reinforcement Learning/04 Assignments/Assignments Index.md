# Assignments Index

## 作业优先级

CS285 作业的目标不是“刷完所有题”，而是用实现打通 deep RL 的关键算法。

优先级：

1. Policy Gradient：必须做。
2. Actor-Critic / PPO：必须做。
3. Q-Learning：建议做。
4. Model-Based RL：如果要接 world model，建议做。
5. Advanced / exploration：按研究需要选做。

## 作业记录模板

每个作业单独建一份记录，包含：

1. 目标算法。
2. 关键公式。
3. 代码入口。
4. 跑通命令。
5. 主要 bug。
6. 结果截图或指标。
7. 和 LLM / agent / world model 的连接。

## 最小完成标准

每个核心作业至少做到：

- 能跑通官方 baseline。
- 能解释 loss 中每一项的来源。
- 能说清楚哪些 hyperparameter 最敏感。
- 能写出一个迁移到当前研究的想法。
