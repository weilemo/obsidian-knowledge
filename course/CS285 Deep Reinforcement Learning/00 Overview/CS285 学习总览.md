# CS285 学习总览

## 课程定位

这门课以 UC Berkeley CS285 / CS185 Deep Reinforcement Learning 为主线，用 Stanford CS234 的核心基础概念做前置桥接。

目标不是泛泛学一遍强化学习，而是服务当前研究转型主线：

1. `LLMTraining / RL 推理训练`：理解 reward、policy optimization、RLVR、RLHF、reasoning trajectory。
2. `CodingAgent`：把 agent 执行轨迹看成 sequential decision making。
3. `AgentMemory`：理解 feedback、verbal reward、reflection memory 如何进入策略改进闭环。
4. `MLLM / video-world-model`：为后续理解决策、控制、world model、offline data 和 evaluation 铺底。

一句话：先用 CS234 补“RL 是什么”，再用 CS285 学“深度 RL 怎么训练、怎么调、怎么接研究”。

## 学习原则

1. CS234 只补必要地基，不完整刷完。
2. CS285 作业优先于泛读论文，因为实现会暴露真正不懂的地方。
3. 每学完一个模块，都要写“它如何迁移到 LLM / agent / memory”的短笔记。
4. 公式必须能解释变量含义，而不是只记形式。
5. 所有算法都用同一个问题框架理解：

$$
\text{agent observes state} \rightarrow \text{chooses action} \rightarrow \text{gets reward} \rightarrow \text{updates policy}
$$

## 8 周学习路径

| 周次 | 主线 | CS234 补充 | CS285 对应模块 | 产出 |
|---|---|---|---|---|

| Week 7 | 接 LLM/Agent 研究 | reward modeling、preference、RLVR | advanced topics + final project | final project proposal |

## 推荐节奏

每周 4 个学习块：

1. 看课：CS234 基础片段或 CS285 正课。
2. 写卡：把核心概念写成 Obsidian 笔记。
3. 做作业：优先跑通代码，不追求一开始就完全优雅。
4. 迁移：写 10-20 行“这和 LLM / agent / memory 有什么关系”。

## 与当前研究的连接

| 当前方向 | RL 里对应的概念 | 为什么要学 |
|---|---|---|
| DeepSeek-R1 / RLVR | policy、reward、trajectory、advantage | 理解为什么 rule-based reward 能推动 reasoning emergence |
| Coding Agent | state、action、environment、long-horizon credit assignment | 把代码编辑、测试、反馈看成 sequential decision process |
| Agent Memory | history、belief state、reflection、feedback | 理解 memory 如何改变 policy 的可观测状态 |
| SWE-bench / code harness | environment、reward signal、evaluation protocol | 把 benchmark 从“打分器”理解成训练环境 |
| Video / world model | dynamics model、planning、model-based RL | 为 world model 与控制类论文铺底 |
