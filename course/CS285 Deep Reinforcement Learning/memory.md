## 定位

本课程文件夹以 UC Berkeley CS285 为主线，用 Stanford CS234 的必要基础做桥接。目标服务当前研究主线：LLM RL 推理训练、Coding Agent、Agent Memory、MLLM / world model，以及 video-world-model quantization。

## 写作规则

- 公式必须使用 LaTeX。块级公式优先使用 `$$...$$`。
- 不把 CS234 完整刷成另一门课；只保留 CS285 需要的基础概念。
- 每个 CS285 模块都要写清楚和 LLM / agent / memory / world model 的连接。
- 作业记录要包含公式、代码入口、运行命令、bug、指标和迁移想法。
