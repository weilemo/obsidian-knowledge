# 从 CS234 到 CS285 的概念迁移

## 核心迁移

CS234 让你掌握 RL 的基础语言。CS285 把这些基础语言换成 neural network、high-dimensional state、continuous action 和实际训练工程。

| CS234 基础 | CS285 中的形态 |
|---|---|
| tabular value $V(s)$ | neural critic $V_\phi(s)$ |
| tabular Q $Q(s,a)$ | Q-network $Q_\theta(s,a)$ |
| policy $\pi(a\mid s)$ | neural policy $\pi_\theta(a\mid s)$ |
| Bellman backup | bootstrapped target |
| TD error | critic loss / advantage estimate |
| policy improvement | actor update |
| known dynamics | learned dynamics model |
| sampled transition | replay buffer / offline dataset |

## 从表格到神经网络

表格方法为每个状态或状态动作对存一个数：

$$
Q(s,a)
$$

deep RL 用神经网络近似：

$$
Q_\theta(s,a)
$$

这带来两个变化：

1. 能处理高维输入，例如图像、token、latent。
2. 训练更不稳定，因为函数近似、bootstrapping 和 off-policy data 会相互影响。

## 从小环境到大模型

传统 RL 的状态可能是棋盘位置或机器人关节角。LLM / agent 里的状态可能是：

$$
s_t=(\text{prompt}, \text{history}, \text{memory}, \text{tool outputs}, \text{workspace state})
$$

动作可能是：

$$
a_t \in \{\text{generate token}, \text{call tool}, \text{edit file}, \text{run test}, \text{retrieve memory}\}
$$

这会让 action space 和 credit assignment 都变得更难。

## 学 CS285 时要特别盯住的问题

1. reward 从哪里来？
2. trajectory 怎么定义？
3. policy update 的 loss 是什么？
4. critic 或 baseline 估计的是什么？
5. 数据是 on-policy 还是 off-policy？
6. 训练失败时，是 reward 问题、分布漂移问题，还是 optimization 问题？
