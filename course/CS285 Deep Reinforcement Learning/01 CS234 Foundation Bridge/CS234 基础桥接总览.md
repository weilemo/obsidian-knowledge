# CS234 基础桥接总览

## 为什么要补 CS234

CS285 默认你已经知道强化学习的基本语言：MDP、value function、Bellman equation、TD learning、Q-learning、policy gradient。

如果直接上 CS285，最容易卡在两类地方：

1. 公式看得懂每个符号，但不知道它在解决什么问题。
2. 算法能跑，但不知道 reward、value、advantage 为什么这样进入 loss。

所以这里不完整刷 CS234，只补 CS285 必须依赖的基础。

## 必补概念清单

| 概念 | 最小掌握标准 | 对 CS285 的作用 |
|---|---|---|
| MDP | 能写出 $\mathcal{S}, \mathcal{A}, P, r, \gamma$ | 所有 RL 算法的统一问题定义 |
| return | 知道 $G_t=\sum_k\gamma^k r_{t+k}$ | policy gradient 的优化目标 |
| value function | 区分 $V^\pi(s)$ 和 $Q^\pi(s,a)$ | critic、baseline、advantage 的基础 |
| Bellman equation | 知道“当前价值 = 当前奖励 + 未来价值” | DP、TD、Q-learning 的基础 |
| TD error | 知道 $\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)$ | actor-critic、GAE 的基础 |
| Q-learning | 知道 off-policy bootstrapping 更新 | DQN、offline RL 的基础 |
| policy gradient | 知道用 $\nabla_\theta \log \pi_\theta(a\mid s)$ 更新策略 | PPO / RLHF / RLVR 的基础 |
| exploration | 知道为什么需要试错 | long-horizon agent 的基础 |
| function approximation | 知道表格方法如何变成神经网络 | deep RL 的入口 |
