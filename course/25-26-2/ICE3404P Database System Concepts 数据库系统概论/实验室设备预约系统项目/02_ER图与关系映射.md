# 02. E-R 图与关系映射

## E-R 图（Mermaid）

```mermaid
erDiagram
    USERS {
        int user_id PK
        string name
        string role
        string email
        string phone
    }

    LABS {
        int lab_id PK
        string lab_name
        string location
    }

    DEVICES {
        int device_id PK
        int lab_id FK
        string device_name
        string device_type
        string status
        int requires_cert
    }

    USER_DEVICE_CERTIFICATIONS {
        int cert_id PK
        int user_id FK
        int device_id FK
        string cert_level
        datetime certified_at
        datetime expires_at
    }

    RESERVATIONS {
        int reservation_id PK
        int user_id FK
        int device_id FK
        datetime start_time
        datetime end_time
        string status
    }

    CHECKIN_LOGS {
        int checkin_id PK
        int reservation_id FK
        datetime checkin_time
        datetime checkout_time
        string result
    }

    MAINTENANCE_ORDERS {
        int order_id PK
        int device_id FK
        int created_by FK
        datetime start_time
        datetime end_time
        string status
    }

    VIOLATION_RECORDS {
        int violation_id PK
        int user_id FK
        int reservation_id FK
        string violation_type
        int penalty_points
    }

    LABS ||--o{ DEVICES : contains
    USERS ||--o{ RESERVATIONS : creates
    DEVICES ||--o{ RESERVATIONS : booked_by
    RESERVATIONS ||--o| CHECKIN_LOGS : has
    DEVICES ||--o{ MAINTENANCE_ORDERS : has
    USERS ||--o{ MAINTENANCE_ORDERS : creates
    USERS ||--o{ USER_DEVICE_CERTIFICATIONS : owns
    DEVICES ||--o{ USER_DEVICE_CERTIFICATIONS : requires
    USERS ||--o{ VIOLATION_RECORDS : gets
    RESERVATIONS ||--o| VIOLATION_RECORDS : may_generate
```

## 从 E-R 到关系模式

- 实体转表：`USERS/LABS/DEVICES/...`
- `1:N`：在 N 端放外键（例如 `devices.lab_id`）
- `N:M`：拆桥接表（`user_device_certifications`）

## 你讲解这页时的重点

1. 核心业务主线：用户-设备-预约
2. 规则增强模块：资质、维护、签到、违约
3. 通过外键把业务关系变成数据库强约束
