# 00. 数据库入门与汇报速读

## 1) 什么是数据库引擎（Engine）

数据库系统可以理解成三层：
- 你写的 SQL（声明你要什么）
- 数据库引擎（决定怎么存、怎么查、怎么保证一致性）
- 磁盘文件（真正保存数据）

引擎就是“数据库的内核实现”，负责：
- 数据存储与读取
- 查询优化与执行
- 事务与并发控制
- 约束与触发器执行

本项目使用 `SQLite` 引擎，它是嵌入式数据库（数据库就是一个 `.db` 文件）。

## 2) 这次项目用什么语言

主要语言：`SQL`
- DDL（定义表结构）：`CREATE TABLE / ALTER TABLE / DROP TABLE`
- DML（操作数据）：`INSERT / UPDATE / DELETE`
- DQL（查询数据）：`SELECT`
- DCL/TCL（权限/事务）：SQLite 支持事务（`BEGIN/COMMIT/ROLLBACK`），权限控制较轻

## 3) SQL 基本语法速记

### 建表（DDL）

```sql
CREATE TABLE users (
  user_id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  role TEXT NOT NULL CHECK (role IN ('student', 'teacher', 'admin'))
);
```

### 插入（DML）

```sql
INSERT INTO users (name, role) VALUES ('张三', 'student');
```

### 查询（DQL）

```sql
SELECT user_id, name
FROM users
WHERE role = 'student'
ORDER BY user_id DESC;
```

### 更新/删除

```sql
UPDATE users SET role = 'teacher' WHERE user_id = 1;
DELETE FROM users WHERE user_id = 2;
```

### 连接查询（Join）

```sql
SELECT r.reservation_id, u.name, d.device_name
FROM reservations r
JOIN users u ON r.user_id = u.user_id
JOIN devices d ON r.device_id = d.device_id;
```

### 视图（View）

```sql
CREATE VIEW vw_active_reservations AS
SELECT * FROM reservations
WHERE status IN ('pending', 'approved');
```

### 触发器（Trigger）

```sql
CREATE TRIGGER trg_time_check
BEFORE INSERT ON reservations
BEGIN
  SELECT CASE
    WHEN NEW.start_time >= NEW.end_time
    THEN RAISE(ABORT, '预约开始时间必须早于结束时间')
  END;
END;
```

## 4) 为什么老师强调“逻辑下沉 DB 层”

因为业务规则放在数据库层后：
- 不会因前端漏校验导致脏数据
- 多个系统接同一数据库时，规则仍一致
- 抽查时可以直接展示“规则在数据库里被强制执行”

## 5) 你汇报时可用的一句话

“我采用 SQL + SQLite，引擎层通过主外键、检查约束、视图和触发器保证业务规则，不依赖应用端才能正确。”
