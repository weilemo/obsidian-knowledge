## 二、按目录分块深度总结

## 1) 树

### 1.1 这一块在讲什么
- 树的基本定义：结点、边、根、双亲、孩子、兄弟、叶结点、内部结点。
- 层次概念：结点层号、树高度（深度）。
- 树的抽象数据类型（ADT）思想：不先关心“怎么存”，先定义“支持哪些操作”。

### 1.2 为什么重要
- 后面每道题的叙述都用这些术语，不熟会直接读不懂题。

### 1.3 必背结论
- 非空树结点数为 $n$ 时，边数为：
$$
n-1
$$
- 树的高度 = 最大层号。

### 1.4 常见考法
- 判断术语（叶子、度、层次）。
- 给结构图求结点数/边数/高度。

### 1.5 易错点
- 把“结点的度”和“树的度”混淆。
- 把“结点深度”与“树高度”混用。

## 2) 二叉树

### 2.1 这一块在讲什么
- 二叉树定义：每个结点最多两个孩子，区分左/右子树。
- 特殊二叉树：满二叉树、完全二叉树。
- 存储方式：顺序存储（数组）与链式存储（左右指针）。
- 遍历：先序、中序、后序、层序。

### 2.2 关键性质（必背）
- 第 $i$ 层最多结点：
$$
2^{i-1}
$$
- 高度为 $h$ 的二叉树最多结点：
$$
2^h-1
$$
- 叶子数与度为 2 的结点关系：
$$
n_0=n_2+1
$$
- 完全二叉树（$n$ 个结点）高度：
$$
\lfloor \log_2 n \rfloor + 1
$$

### 2.2.1 小例子（快速代入）
- 若二叉树高度 $h=4$，最多结点数：
$$
2^4-1=15
$$
- 若某二叉树中 $n_2=6$，则叶子数：
$$
n_0=n_2+1=7
$$

### 2.3 课件实现思路（类模板方向）
- `Node` 里至少有：`data`, `left`, `right`。
- `BTree` 对外提供：建树、遍历、`Size()`、`Height()` 等。
- 递归是核心实现范式。

### 2.4 代码模板（做题可直接改）
```cpp
int Size(Node* t){
    if(t == nullptr) return 0;
    return 1 + Size(t->left) + Size(t->right);
}

int Height(Node* t){
    if(t == nullptr) return 0;
    int hl = Height(t->left);
    int hr = Height(t->right);
    return 1 + (hl > hr ? hl : hr);
}
```

### 2.4.1 非递归遍历速记
- 先序（根-左-右）：栈，出栈访问后先压右再压左。
- 中序（左-根-右）：一路压左，弹栈访问，再转向右子树。
- 后序（左-右-根）：可用“双栈法”或“一个栈+上次访问指针”。
- 层序：队列，出队访问，左孩子和右孩子依次入队。

### 2.5 典型题
- 给数组下标关系判断父子编号（顺序存储）。
- 写 4 种遍历（递归和非递归）。
- 求总结点数、叶子数、高度。

### 2.6 易错点
- 非递归先序时压栈顺序写反（应先压右再压左）。
- 层序遍历漏判空根导致 RE。
- 完全二叉树下标从 0/1 开始混乱。

## 3) 遍历序列确定二叉树

### 3.1 这一块在讲什么
- 通过遍历序列恢复树结构。

### 3.2 唯一性结论
- 先序 + 中序：可唯一确定。
- 后序 + 中序：可唯一确定。
- 先序 + 后序：一般不唯一（除非附加“满二叉树”等条件）。

### 3.3 先序 + 中序重建步骤
1. 先序区间首元素是根。
2. 在中序中找到根位置，分出左/右子树长度。
3. 按长度切分先序区间，递归重建左右子树。

### 3.3.1 小例子
- 先序：`1 2 4 5 3`
- 中序：`4 2 5 1 3`
- 根是 `1`，中序中 `1` 左边是左子树 `4 2 5`，右边是右子树 `3`，继续递归即可。

### 3.4 复杂度
- 若每次线性找根：
$$
O(n^2)
$$
- 若先建下标表（哈希）：
$$
O(n)
$$

### 3.5 模板框架
```cpp
Node* build(preL, preR, inL, inR){
    if(preL > preR) return nullptr;
    int rootVal = pre[preL];
    int k = pos[rootVal]; // 中序位置
    int leftLen = k - inL;
    Node* root = new Node(rootVal);
    root->left = build(preL+1, preL+leftLen, inL, k-1);
    root->right = build(preL+leftLen+1, preR, k+1, inR);
    return root;
}
```

### 3.6 易错点
- 区间边界少一位或多一位。
- `leftLen` 算错后整棵树错位。

## 4) 最优二叉树（哈夫曼树）

### 4.1 这一块在讲什么
- 带权路径长度（WPL）最小化。
- 哈夫曼树构造（每步合并最小两棵树）。

### 4.2 核心定义
- 叶子权值为 $w_i$，根到该叶路径长度为 $l_i$，则：
$$
WPL=\sum_i w_i l_i
$$

### 4.3 构造算法（贪心）
1. 把所有权值放入最小堆。
2. 反复取出最小两项 $x,y$ 合并成 $x+y$ 再入堆。
3. 直到堆只剩一个元素。

### 4.3.1 小例子
权值 `2,3,7,9`：
1. 先合并 `2+3=5`
2. 再合并 `5+7=12`
3. 再合并 `9+12=21`
合并过程越早出现的结点层数越深，所以“先合并小权值”能减少总加权代价。

### 4.4 复杂度
$$
O(n\log n)
$$

### 4.5 为什么它“最优”
- 每次把当前代价最小的两棵先合并，能保证全局 $WPL$ 最小（贪心选择性质）。

### 4.6 易错点
- 把“权值最小两项”写成“前两项”。
- 混淆“边数路径长度”和“结点层号”。

## 5) 树和森林

### 5.1 这一块在讲什么
- 一般树、森林与二叉树的等价表示。
- 孩子-兄弟表示法（左孩子右兄弟）。

### 5.2 映射规则（必背）
- `left` 指向第一个孩子。
- `right` 指向下一个兄弟。

### 5.3 实战意义
- 可把“多叉树问题”转成“二叉树问题”统一处理。

### 5.4 常见题型
- 给一般树画对应二叉树。
- 给森林求对应二叉树结构。

### 5.5 易错点
- 把 `right` 误解成“右孩子”，在该表示中它是“兄弟”。

## 6) 二叉线索树

### 6.1 这一块在讲什么
- 利用空指针域保存遍历前驱/后继线索，减少遍历时辅助栈需求。

### 6.2 核心机制
- 若左孩子为空，则左指针改存前驱。
- 若右孩子为空，则右指针改存后继。
- 需要标志位（如 `ltag/rtag`）区分“孩子指针”与“线索指针”。

### 6.2.1 中序线索树判定规则
- `ltag=0`：`left` 指向左孩子；`ltag=1`：`left` 指向中序前驱。
- `rtag=0`：`right` 指向右孩子；`rtag=1`：`right` 指向中序后继。

### 6.3 常见考点
- 中序线索化后某结点前驱/后继是谁。
- 给线索树判断遍历下一个结点。

### 6.4 易错点
- 忘了判断 `tag` 就直接当孩子走，导致访问错误。

---

## 7) 表达式树

### 7.1 这一块在讲什么
- 叶子是操作数，内部结点是运算符。
- 一棵树对应前缀/中缀/后缀三种表达式。

### 7.2 对应关系
- 先序遍历 $\leftrightarrow$ 前缀表达式
- 中序遍历 $\leftrightarrow$ 中缀表达式（通常要补括号）
- 后序遍历 $\leftrightarrow$ 后缀表达式

### 7.3 后缀建树（高频）
1. 扫描后缀串。
2. 遇操作数：入栈一个单结点树。
3. 遇运算符：弹出两棵树，前弹为右子树、后弹为左子树，合成新树再入栈。
4. 最后栈顶即根。

### 7.4 表达式树求值
- 常用后序遍历：先算左子树，再算右子树，最后算根运算符。

### 7.4.1 小例子
- 表达式：`(3+5)*2`
- 后缀：`3 5 + 2 *`
- 后缀建树后做后序计算，结果为 `16`。

### 7.5 易错点
- 两次出栈左右顺序颠倒（会把减法/除法算反）。

## 8) 等价关系（并查集）

### 8.1 这一块在讲什么
- 用不相交集合维护“是否同类/是否连通”。

### 8.2 操作定义
- `find(x)`：返回代表元（根）。
- `union(x,y)`：合并两个集合。

### 8.3 两个优化（必会）
- 路径压缩：
$$
\text{parent}[x] \leftarrow \text{find}(\text{parent}[x])
$$
- 按秩/按大小合并：小树挂到大树下。

### 8.4 复杂度
$$
O(\alpha(n))
$$
其中 $\alpha(n)$ 是反 Ackermann 函数，增长极慢，工程上近似常数。

### 8.5 模板
```cpp
int find(int x){
    if(parent[x] != x) parent[x] = find(parent[x]);
    return parent[x];
}

void unite(int x, int y){
    x = find(x); y = find(y);
    if(x == y) return;
    if(sz[x] < sz[y]) swap(x, y);
    parent[y] = x;
    sz[x] += sz[y];
}
```

### 8.6 易错点
- `union` 前不 `find`，导致错连。
- 路径压缩写错成死递归。

## 9) 优先级队列

### 9.1 这一块在讲什么
- “先来后到”改为“按优先级先后”。
- 二叉堆是最常见实现。

### 9.2 堆的核心性质
- 最小堆：父结点键值 $\le$ 子结点键值。
- 最大堆：父结点键值 $\ge$ 子结点键值。

### 9.3 三个核心操作复杂度
$$
T_{\text{top}} = O(1), \quad T_{\text{push}} = O(\log n), \quad T_{\text{pop}} = O(\log n)
$$

### 9.3.1 堆调整步骤（代码思维）
- 插入 `push`：先放末尾，再“上滤”（与父比较并交换）。
- 删除堆顶 `pop`：末尾元素补到堆顶，再“下滤”（与更优孩子比较并交换）。
- 关键是每次只走一条根到叶路径，所以是：
$$
O(\log n)
$$

### 9.4 课件应用方向
- 事件驱动模拟（如单服务窗口）：
  - 等待队列：普通队列；
  - 事件队列：优先级队列（按最早事件时间先处理）。

### 9.5 易错点
- 把“高优先级”方向写反（最大堆/最小堆与题意不匹配）。
- 调整堆时父子下标计算错误。

## 三、核心定义速查（做题时可秒看）

- 树：无环连通结构。
- 二叉树：每个结点最多两个孩子，且有左右之分。
- 完全二叉树：除最后一层外都满，最后一层从左到右连续。
- 哈夫曼树：在给定叶权的二叉树中，$WPL$ 最小的树。
- 线索树：用空链域存前驱/后继的二叉树。
- 并查集：支持集合查询与合并的数据结构。
- 优先级队列：按优先级而非入队顺序出队的队列。

## 四、复杂度汇总（全章高频）

1. 二叉树遍历（先/中/后/层）：
$$
O(n)
$$

2. 递归遍历额外栈空间（$h$ 为树高）：
$$
O(h)
$$

3. 先序+中序重建（带下标表）：
$$
O(n)
$$

4. 哈夫曼构造（最小堆）：
$$
O(n\log n)
$$

5. 并查集（路径压缩+按秩/按大小）：
$$
O(\alpha(n))
$$

6. 优先级队列（二叉堆）：
$$
\text{top}:O(1),\ \text{push/pop}:O(\log n)
$$

## 五、易错点清单（考前必看）

1. 先序非递归时，压栈顺序应“右后左先”，否则访问顺序错。
2. 先序+中序重建中，左子树长度公式写错会导致整棵树错位。
3. 后缀表达式建树时，两次弹栈顺序不能反（先弹右、后弹左）。
4. 线索树中不看 `tag` 就沿指针走，容易把线索当孩子。
5. 并查集合并时没先 `find` 根，容易形成错误父子关系。
6. 完全二叉树下标规则（从 0 或从 1）混用，父子编号公式全错。
7. 堆的“高优先级是大还是小”没先和题目约定对齐。

## 六、30 秒速记卡片

- 树：$n$ 个结点一定有 $n-1$ 条边。
- 二叉树四个核心：
$$
2^{i-1},\ 2^h-1,\ n_0=n_2+1,\ h=\lfloor\log_2 n\rfloor+1
$$
- 重建唯一性：先/后 + 中可以，先+后一般不行。
- 哈夫曼：每次取最小两项合并，目标是最小 $WPL$。
- 树森林互转：左孩子右兄弟。
- 并查集：`find + union`，优化后近似常数。
- 优先队列（堆）：`top O(1)`，`push/pop O(\log n)`。
