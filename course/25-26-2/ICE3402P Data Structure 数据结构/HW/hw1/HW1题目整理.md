# HW1 题目整理（线性表与链表）

## 题目 1：两个非负整数（链表表示）求和

### 题目目标
- 给定两个非空链表，分别表示两个非负整数（每个结点存一位）。
- 计算它们的和，并用同样形式输出。

### 输入输出要点
- 输入：
  - 第一行：`m n`（两个整数的位数）
  - 第二行：第一个数的各位
  - 第三行：第二个数的各位
- 输出：
  - 一行，和的各位

### 复习重点
- 链表逆置（把高位在前转成低位在前，便于逐位相加）
- 进位 `carry` 处理
- 长度不等时的补位思想（谁空了就当 `0`）

### 复杂度
- 时间复杂度：$O(m+n)$
- 空间复杂度：$O(m+n)$（结果链表）

### 易错点
- 最后 `carry` 不为 `0` 时漏建新结点
- 相加后忘记把结果链表再逆置回正常顺序

## 题目 2：单链表逆置

### 题目目标
- 输入一组整数先建链表，再将链表原地逆置并输出。

### 输入输出要点
- 输入：
  - 第一行：`n`
  - 第二行：`n` 个整数
- 输出：
  - 逆置后的 `n` 个整数

### 复习重点
- 三指针逆置法：`pre / cur / nxt`
- 逆置完成后新表头是 `pre`

### 复杂度
- 时间复杂度：$O(n)$
- 空间复杂度：$O(1)$

### 易错点
- 先改 `cur->next` 再保存后继会断链（顺序必须先存 `nxt`）

## 题目 3：两个递增序列的“对称差去重”

### 题目目标
- 已知两个按非递减顺序排列的序列 `A`、`B`。
- 输出只在 `A` 或只在 `B` 中出现的元素（两边都出现的删掉）。
- 同时要求同一数值在输出中只保留一次。
- 若结果为空，输出 `Empty`。

### 输入输出要点
- 输入：
  - 第一行：`n m`
  - 第二行：`A`
  - 第三行：`B`
- 输出：
  - 对称差结果（升序，空格分隔）；若空则 `Empty`

### 复习重点
- 双指针合并思想
- “跳过重复值”技巧（`while` 连续跳同值）

### 复杂度
- 时间复杂度：$O(n+m)$
- 空间复杂度：$O(n+m)$（最坏情况下结果数组）

### 易错点
- `A[i]==B[j]` 时只移动一个指针会出错（应两边都跳过该值）
- 去重处理不完整会导致重复输出
