# Project Memory

用途：维护计算机体系结构课程大作业项目的长期记忆，供 Codex、Claude Code 或其他 agent 进入本项目时优先阅读。

## 使用规则

- 先确认当前项目文件、测试命令、提交包命名和作业要求，再继续实现或解释。
- 不要把下载到的公开参考实现包装成用户原创完成品；需要明确区分“参考/对照/学习材料”和用户自己的提交内容。
- 产出说明文档时要面向课程交付：设计思路、模块职责、测试结果、限制和可复现实验步骤要清楚。
- 涉及公式、流水线、缓存、性能指标或时序推导时，用 LaTeX 书写公式。
