# 参考答案先不看规则

## 1. 禁看区

为了保证项目是自己理解后做出来，下面这些暂时不要人工打开：

```text
tests/**/reference_output/
tests/**/student_output/ 中已经生成的历史输出
实现思路说明.md
../莫炜乐_计算机体系结构大作业.zip
../莫炜乐_计算机体系结构大作业.zip
```

说明：`reference_output` 是测试框架自动比对需要的，不能删除，也不需要移动。我们只是不手动打开它。

## 2. 可看区

可以看：

```text
Project.pdf
README.md 的环境/命令部分
CS61C 课程讲义
00_project_notes/
tests/**/inputs/*.s
tests/**/inputs/*.hex
test_runner.py 的命令用法
```

其中 `inputs/*.s` 可以看，因为它只是测试程序，不是答案。

## 3. 测试输出怎么用

可以运行：

```bash
python3 test_runner.py part_a alu
```

如果失败，先看终端报错和自己的电路。

只有在需要确认格式时，才看 `student_output`，并且不要和 `reference_output` 人工逐行对答案。

更推荐的调试方式：

```text
打开 harness
手动 tick clock
probe 关键信号
确认数据流是否符合自己推导
```

## 4. 如果发现当前工程已经是完成版

当前 `README.md` 提到工程曾经通过所有测试，因此 `cpu/*.circ` 可能已经包含完成实现。

这意味着：

```text
不要把当前电路当作学习起点直接照抄
```

如果要从零练习，有两个办法：

1. 从课程 starter 重新下载一份干净工程。
2. 保留当前工程作为参考区，另建一份练习副本，从每个模块的空框架开始重搭。

在没有干净 starter 之前，先按讲义和 Project.pdf 做纸面推导，再决定是否需要重新获取 starter。
