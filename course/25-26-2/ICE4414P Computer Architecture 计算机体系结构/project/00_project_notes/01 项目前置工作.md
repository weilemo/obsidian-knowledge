## 3. 不要破坏这些接口

项目测试依赖输入输出 pin 的位置和形状。

不要移动这些文件中的外部接口：

```text
cpu/alu.circ
cpu/regfile.circ
cpu/cpu.circ
cpu/imm_gen.circ
cpu/branch_comp.circ
cpu/control_logic.circ
cpu/csr.circ
```

可以在内部添加 wire、MUX、splitter、tunnel、subcircuit，但不要改变已有 pin 的名字、位宽、位置。

## 4. 推荐开工顺序

### Step 1: ALU

文件：

```text
cpu/alu.circ
```

目标：

```text
A, B, ALUSel -> Result
```

测试：

```bash
python3 test_runner.py part_a alu
```

### Step 2: RegFile

文件：

```text
cpu/regfile.circ
```

目标：

```text
32 registers
x0 always 0
2 read ports
1 write port
clock not gated
```

测试：

```bash
python3 test_runner.py part_a regfile
```

### Step 3: addi single-cycle CPU

文件：

```text
cpu/cpu.circ
cpu/imm_gen.circ
```

目标：

```text
addi rd, rs1, imm
R[rd] = R[rs1] + SignExt(imm)
PC = PC + 4
```

测试：

```bash
python3 test_runner.py part_a addi_single
```

### Step 4: addi pipelined CPU

目标：

```text
Stage 1: IF
```

测试：


## 5. 每次做电路的工作流

推荐：

```text
读 Project.pdf 对应任务
只改一个模块
保存 .circ
跑对应最小测试
看 student_output 或测试报错
回到 Logisim 修
再跑测试
```

不要一次性改完整 CPU。

## 6. 当前最重要的心智模型

```text
ALU 是组合逻辑，不需要 clock
RegFile 是状态元件，写入需要 clock
ImmGen 是组合逻辑，负责 sign extension
control_logic 是组合逻辑，负责生成选择信号
cpu.circ 是把所有模块连起来的数据通路
```

一句话：

```text
先让 addi 跑通，再扩展指令集。
```
