# 计算机体系结构（Chapter 1）- 取指与执行流程图详解

## 1. 图的整体作用

这张图展示的是经典的“单内部总线 CPU 数据通路 + 控制器”模型，用于说明一条指令如何经历取指（fetch）、译码（decode）和执行（execute）。

## 2. 整体结构

1. 左侧是主存（Memory），同时存放指令和数据。  
2. 中间是 CPU 内部寄存器堆与 ALU。  
3. 右侧竖直箭头是 Internal Bus（内部总线），负责 CPU 内部数据传送。  
4. 顶部是 Control Circuit 与 Instruction Decoder，负责生成控制信号。  
5. CPU 和内存之间通过 Address Bus 与 Data Bus 交换地址和数据。

## 3. 每个组成部分逐个解释

1. `Memory`  
存放程序指令和数据。图中示例指令为 `LOAD R1,M1`、`ADD R1,M2`、`STORE M3,R1`；数据示例为 `M1=a, M2=b, M3=c`。

2. `Address Bus`（地址总线）  
一般由 CPU 向内存发送访问地址，地址来源通常是 `MAR`。

3. `Data Bus`（数据总线）  
双向总线：读内存时数据流向 CPU；写内存时数据流向内存。

4. `Control Signals`（控制信号）  
由控制器发出，用于触发寄存器装载、ALU 运算、内存读写等微操作。

5. `Control Circuit`（控制电路）  
按时钟节拍组织执行顺序，是整个执行流程的时序指挥中心。

6. `Instruction Decoder`（指令译码器）  
读取 `IR` 中的指令，识别操作码和操作数，决定后续控制路径。

7. `IR`（Instruction Register）  
当前指令寄存器，保存正在执行的那条指令。

8. `PC`（Program Counter）  
程序计数器，保存下一条要取的指令地址。顺序执行时递增，分支时改写。

9. `MAR`（Memory Address Register）  
内存地址寄存器，保存当前内存访问地址并驱动地址总线。

10. `MDR`（Memory Data Register）  
内存数据寄存器，保存从内存读出的数据或待写回内存的数据。

11. `R0 ... Rn-1`（通用寄存器组）  
存放操作数和中间结果，是算术逻辑运算的核心工作区。

12. `Y`  
ALU 输入暂存寄存器之一。常把一个操作数先放入 `Y`，另一个经总线送入 ALU。

13. `ALU`（Arithmetic Logic Unit）  
执行加减、逻辑运算等，结果写入 `Z`，并更新标志位 `F`。

14. `Z`  
ALU 结果寄存器，供后续写回寄存器或内存。

15. `F`（Flags）  
状态标志寄存器（如 Zero、Carry、Negative、Overflow），用于条件判断与控制流。

16. `Internal Bus`（内部总线）  
CPU 内部共享传输通道。单总线结构下，复杂操作通常分多个时钟周期完成。

## 4. 三条示例指令的执行过程

1. `LOAD R1, M1`  
`MAR <- M1地址`，发起读内存；`MDR <- Memory[MAR]`；`R1 <- MDR`，最终 `R1=a`。

2. `ADD R1, M2`  
`Y <- R1`；`MAR <- M2地址` 并将 `b` 读入 `MDR`；`Z <- Y + MDR`；`R1 <- Z`，最终 `R1=a+b`。

3. `STORE M3, R1`  
`MAR <- M3地址`；`MDR <- R1`；发起写内存，`Memory[MAR] <- MDR`，最终 `M3=a+b`。

## 5. 一句话总结

取指与执行的本质是：控制器在时钟驱动下发出控制信号，让寄存器、ALU、总线和内存按顺序完成微操作，从而把指令语义落实为硬件动作。

## 6. Power and Energy（功耗与能量）怎么理解

这一页可以抓住三个核心关系：

$$
\text{Power}=\text{Dynamic Power}+\text{Static Power}
$$

$$
\text{Energy}=\text{Power}\times\text{Time}
$$

$$
\text{Dynamic Power}\propto \frac{1}{2}\times C\times V^2\times f
$$

其中 $C$ 是等效电容，$V$ 是电压，$f$ 是频率。

### 6.1 动态功耗（Dynamic Power）

1. 动态功耗来自晶体管翻转（switching）。  
2. 在公式中，电压是平方项，所以降压对动态功耗影响最大。  
3. 频率越高，单位时间翻转越多，动态功耗越高。  
4. 时钟门控（Clock Gating）通过减少无效翻转来降低动态功耗。

### 6.2 静态功耗（Static Power）

课件给出：

$$
\text{Static Power}=\text{Static Current}\times\text{Voltage}
$$

静态功耗主要由漏电流导致，即使不切换也会耗电。电源门控（Power Gating）能直接关闭不用模块，显著降低静态功耗（同时也抑制该模块动态功耗）。

### 6.3 DVFS 的本质取舍

动态电压频率调整（DVFS）的逻辑是：

1. 降低电压可显著降功耗。  
2. 但通常必须同时降低频率以保证电路稳定。  
3. 降频会让执行时间变长。  
4. 若功耗下降幅度大于时间增长幅度，则总能量仍会下降（因为 $E=P\times T$）。

### 6.4 Race-to-halt 与 Dark Silicon

1. `Race-to-halt`：先用较高性能快速完成任务，再尽快进入低功耗状态。  
2. `Dark Silicon`：受功耗和散热限制，芯片上并非所有单元都能长期同时高性能运行，总有一部分资源在任意时刻需要“暗着”。

### 6.5 这页的考试向总结

1. 看功耗拆分：先分动态和静态。  
2. 看优化手段：Clock Gating 管动态，Power Gating 管静态。  
3. 看能量优劣：永远回到 $E=P\times T$，同时比较功耗变化和执行时间变化。
