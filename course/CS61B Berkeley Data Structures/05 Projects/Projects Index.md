# Projects Index

## 项目原则

CS61B 的项目是本课程的核心。做项目时重点不是“凑到通过”，而是训练：

1. 从 specification 读出 API 和行为约束。
2. 用 invariant 维护实现正确性。
3. 用测试先锁住边界情况。
4. 用 debugger 和小步提交排查 bug。
