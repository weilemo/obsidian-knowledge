# Labs Index

## Lab 记录模板

每个 lab 建议记录：

- 目标：这个 lab 想训练什么。
- 起始状态：starter code 有哪些文件。
- 实现步骤：按函数或类记录。
- 测试：跑了哪些 test。
- Bug：现象、原因、修复。
- 复盘：这次学到的工程习惯。
