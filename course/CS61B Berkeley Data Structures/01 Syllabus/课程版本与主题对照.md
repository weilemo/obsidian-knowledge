# CS61B 课程版本与主题对照

## 推荐策略

自学时采用双轨：

1. `Spring 2021` 作为主线：公开资料、项目 skeleton、library 和 autograder 比较完整。
2. 当前 `cs61b.org` 作为补充：用于查看新版 lecture、教材链接、课程主题是否有更新。

## 主题地图

| 模块 | CS61B 关键词 | 应该掌握到什么程度 |
|---|---|---|
| Java 入门 | class、reference、static、inheritance、interface | 能读懂 starter code，能写小型类 |
| Lists | IntList、SLList、DLList、AList | 能解释 linked vs array 的取舍 |
| Testing | JUnit、randomized testing、debugger | 能用测试定位 bug，而不是只靠 autograder |
| Generics | generic class、generic method、iterator | 能写通用容器 |
| Complexity | Big-O、amortized analysis | 能分析核心操作复杂度 |
| Trees | BST、B-tree、red-black tree | 能用 invariant 解释查找和更新 |
| Hashing | hashCode、collision、resizing | 能实现简化 HashMap |
| Heaps | binary heap、priority queue | 能实现 add/removeMin |
| Graphs | BFS、DFS、Dijkstra、A*、MST | 能把算法映射到图状态变化 |
| Software Engineering | style、design、large project | 能拆解项目并维护不变量 |

## 与本地课程 `ICE3402P Data Structure 数据结构` 的对照

之后复习时可以把 CS61B 当成工程实现侧，把本校数据结构当成理论/中文理解侧：

| 本地数据结构课 | CS61B 对应补强 |
|---|---|
| 线性表、栈、队列 | List / Deque project |
| 树和二叉树 | BST / balanced tree |
| 哈希表 | HashMap implementation |
| 堆和优先队列 | Heap / PriorityQueue |
| 图 | Graph algorithms project / discussion |
| 算法复杂度 | Big-O + amortized analysis |
