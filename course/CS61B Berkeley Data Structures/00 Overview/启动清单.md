# CS61B 启动清单

## 第一小时

- [ ] 确认 JDK 版本。
- [ ] 确认 IntelliJ IDEA 可用。
- [ ] 克隆 `skeleton-sp21`。
- [ ] 克隆 `library-sp21`。
- [ ] 打开课程主页 <https://sp21.datastructur.es/>。
- [ ] 建立本地代码路径记录。

## 第一周结束前

- [ ] 跑通一个 JUnit 测试。
- [ ] 完成第一个 lab。
- [ ] 写完 `Java 与 OOP 速查.md`。
- [ ] 记录 3 个 Java 初学坑。

## 第一个项目结束前

- [ ] 每个 public method 都有基本测试。
- [ ] 至少写一个 randomized test。
- [ ] 记录一次 debugger 使用过程。
- [ ] 写项目复盘：设计、bug、复杂度、下次怎么做。

## 本课程不要这样学

- 不要只看视频不写代码。
- 不要把项目当成一次性作业，做完就丢。
- 不要跳过测试直接靠 autograder。
- 不要只背复杂度，要能解释为什么是这个复杂度。
