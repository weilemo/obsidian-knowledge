# CS61B 暑假 8 周学习路径

## 使用方式

这份路线按“能实际完成项目”的节奏设计。不要只刷 lecture；每周都要有代码产出、bug 复盘和一页可复习笔记。

默认主线：

- 课程页面：<https://sp21.datastructur.es/>
- 作业代码：<https://github.com/Berkeley-CS61B/skeleton-sp21>
- 支撑库：<https://github.com/Berkeley-CS61B/library-sp21>

## Week 0：环境准备

目标：让 Java / IntelliJ / Git / JUnit / skeleton 能跑起来。

要做：

1. 安装或确认 JDK。
2. 安装 IntelliJ IDEA。
3. 克隆 `skeleton-sp21` 和 `library-sp21`。
4. 跑通一个最小 JUnit 测试。
5. 建立 `08 Code/README.md` 中的本地 repo 路径记录。

产出：

- `08 Code/README.md`
- `02 Units/Java 环境与工具链.md`

## Week 1：Java 与面向对象

目标：能读懂 CS61B 的 starter code。

主题：

- primitive vs reference
- class / object / constructor
- static vs instance
- inheritance / interface
- generic type
- Java memory model 的最小直觉

练习：

- Lab 1 / Lab 2
- 小练习：自己写一个 `IntList` / `SLList`

产出：

- `02 Units/Java 与 OOP 速查.md`

## Week 2：List / Deque

目标：能从 API specification 实现一个数据结构。

主题：

- ADT vs implementation
- singly linked list / doubly linked list
- array resizing
- sentinel node
- iterator
- generic array 的坑

练习：

- Project 0
- Project 1 启动

产出：

- `05 Projects/Project 1 Deque 实现记录.md`

## Week 3：测试与 Debugging

目标：让项目不靠运气通过。

主题：

- JUnit
- randomized testing
- edge cases
- debugger
- style checker
- invariant-based debugging

练习：

- 完成 Project 1

产出：

- `04 Labs/Testing 与 Debugging 复盘.md`
- `05 Projects/Project 1 Deque 复盘.md`

## Week 4：Trees

目标：掌握树结构的 invariant。

主题：

- recursion on trees
- binary search tree
- balanced tree intuition

- tree traversal

练习：

- Tree 相关 lab / discussion

产出：

- `02 Units/Trees 与 Search Trees.md`

## Week 5：Hashing / Heap / Priority Queue

目标：掌握高频工程数据结构。

主题：

- resizing

- priority queue
- amortized analysis

练习：

## Week 6：Graphs

目标：把图算法从“背模板”变成“能解释状态变化”。

- `02 Units/Graph Algorithms 速查.md`

## Week 7：项目收束与复习

目标：形成以后可翻的 CS61B 知识包。

要做：

1. 选一个大项目深入做或复盘，例如 Gitlet / BYOW。
2. 做 1-2 套 past exam / review worksheet。
3. 整理 final review packet。
4. 把所有项目的 bug 复盘合并成“常见错误表”。

产出：

- `07 Exams/Final Review Packet.md`
- `05 Projects/项目 Bug 复盘总表.md`
