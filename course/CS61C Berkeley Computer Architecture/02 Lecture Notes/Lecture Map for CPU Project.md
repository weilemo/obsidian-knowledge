# Lecture Map for CPU Project

## 项目优先版观看顺序

| 顺序 | CS61C 内容 | 用途 |
|---|---|---|
| 1 | L01 Intro, Great Ideas | 建立从程序到硬件的层次 |
| 2 | L02 Number Representation | 二进制、补码、符号扩展、位操作 |
| 3 | L09 RISC-V Basics | 寄存器、基础整数指令 |
| 4 | L10 RISC-V Data Transfer | load/store、地址、内存 |
| 5 | L13-L14 RISC-V Instruction Formats | R/I/S/B/U/J 型指令格式 |
| 6 | L16-L20 Synchronous Digital Systems | 组合逻辑、寄存器、ALU |
| 7 | L21-L23 Single-Cycle CPU | CPU 数据通路与控制逻辑 |
| 8 | L24-L25 Pipelining | 流水线与 hazard |
| 9 | L26-L29 Caches | 课程第二章与内存层次 |
