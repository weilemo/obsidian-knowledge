# 课程笔记规则

适用范围：`/Users/moweile/Obsidian/Knowledge/Course`

## 1. 总原则
1. 写课程笔记时，优先保证可复习、可检索、可持续扩展。
2. 如果已有合适笔记，优先更新已有笔记；如果用户明确要求保留旧版本，则新建并区分用途。
3. 数学类内容统一使用 LaTeX 语法：
   - 块级公式使用 `$$...$$`
   - 行内公式使用 `$...$`

## 2. 解题与证明规范
1. 任何用到的公式，必须先说明来源或给出推导。
2. 不默认读者已知某个公式、定理或技巧。
3. 若使用“已知公式”，必须补充：
   - 公式成立条件；
   - 当前题目或当前上下文为什么可以使用；
   - 至少一种简要推导或直观解释。
4. 涉及概率统计中的几何体积法、隔板法、顺序统计量、边缘分布、条件分布等概念时，先讲直觉，再讲数学表达。

## 3. 总结笔记双版本规则
当用户要求“写总结笔记”“整理课件笔记”“总结这一讲”时，默认产出两份笔记：

### 3.1 考试复习版笔记
定位：考前快速复习。

应包含：
1. 本讲核心知识框架。
2. 必背公式与使用条件。
3. 高频题型与解题套路。
4. 易错点、易混点、常见陷阱。
5. 尽量短、密度高、便于扫读。

### 3.2 讲义版笔记
定位：替代或尽量接近替代课件阅读体验。

应包含：
1. 按授课逻辑展开，而不是只罗列结论。
2. 课件主要内容要尽量覆盖完整，不只保留提纲。
3. 每个知识点要尽量写出：
   - 为什么要引入这个概念；
   - 概念的直觉解释；
   - 标准定义；
   - 关键公式；
   - 公式推导或证明思路；
   - 典型例子；
   - 和前后知识点的联系。
4. 风格应当“能讲清楚”，目标是让读者即使不看原课件，也能跟上主要思路。

## 4. 文件管理规则
1. 考试复习版和讲义版应明确区分命名，避免混淆用途。
2. 如果原有总结笔记已经适合作为考试复习版，默认保留，不强行改写。
3. 如果需要补充讲义版，应单独创建，不覆盖考试复习版。
4. 除非用户要求合并，否则不要把两种用途的内容混写在同一文件中。

## 5. 当前执行约定
从现在开始：
1. “总结笔记”默认理解为需要区分“考试复习版”和“讲义版”。
2. 如果用户没有特别说明，优先保留现有复习版，再补写讲义版。
