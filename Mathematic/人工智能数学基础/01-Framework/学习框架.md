# 学习框架

这份笔记的作用不是讲“怎么学”，而是回答：

$$
\text{我到底要学哪些内容？现在学到哪了？}
$$

你可以把它当成这套学习系统的`内容地图`。

## 怎么用这份框架

每个模块都按同样的方式看：
- `为什么要学`：它在研究里解决什么问题
- `核心内容`：具体要掌握哪些知识点
- `过关标准`：学到什么程度才算真的过了

你不需要一开始把所有模块都学完。更合理的做法是：
- 先完成前四个基础模块
- 再进入训练 / 推理常用模块
- 最后再碰更研究化的主题

## 进度刻度尺

为了知道“自己学到哪”，统一用这五档：

### L0：未建立
- 看到概念会怕
- 记不住定义
- 公式基本看不懂

### L1：有直觉
- 能用自己的话解释大意
- 看别人推导时大概知道在干嘛
- 但还不太能自己写

### L2：会计算 / 会推导
- 能做基础计算
- 能补全关键中间步骤
- 能自己手推最基本结论

### L3：会应用到论文
- 看到论文时能认出它
- 知道它在模型里起什么作用
- 能把它和实验 / 训练连接起来

### L4：会用它分析研究问题
- 能用它拆解论文
- 能判断某个理论说法站不站得住
- 能把自己的想法写成更清晰的目标函数或推导

你以后给自己打标时，可以直接写：
- 线性代数：`L3`
- 概率：`L2`
- 采样与估计：`L1`

## 全部学习模块

## 模块 1：线性代数与符号系统

### 为什么要学
这是读模型公式的语言底座。  
如果这一层不稳，你看任何训练公式都会卡在“对象到底是什么”。

### 核心内容
- 标量、向量、矩阵
- 维度与形状
- 线性方程组
- 矩阵乘法
- 内积
- 范数
- 投影
- 特征值 / 特征向量
- 正定矩阵
- SVD 的基本直觉

### 过关标准
- `L1`：能看懂向量、矩阵、维度写法
- `L2`：会算矩阵乘法、内积、范数；知道矩阵是线性变换
- `L3`：看到 $Wx+b$、attention score、正则项时能立刻识别结构
- `L4`：能用矩阵视角分析表示变换、低秩、谱性质等问题

## 模块 2：多元微积分与梯度

### 为什么要学
这是读训练推导的语言底座。  
如果这一层不稳，你会一直知道“模型在更新”，但不知道“为什么这样更新”。

### 核心内容
- 偏导数
- 梯度
- Jacobian 的直觉
- Hessian 的直觉
- 链式法则
- 一阶近似
- 梯度下降为什么往负梯度走
- 反向传播和链式法则的关系

### 过关标准
- `L1`：知道偏导和梯度在描述局部变化
- `L2`：能对简单多元函数求梯度
- `L3`：能读懂基础 backprop 和训练更新式
- `L4`：能用一阶 / 二阶信息解释优化稳定性

## 模块 3：概率基础

### 为什么要学
这是读不确定性、latent variable、推理与采样论文的底座。

### 核心内容
- 概率、随机变量
- 联合分布、边缘分布
- 条件概率
- 贝叶斯公式
- 期望、方差、协方差
- 条件期望
- 马尔可夫链
- HMM 的基本结构

### 过关标准
- `L1`：能理解条件概率和后验的直觉
- `L2`：能做基础概率与期望计算
- `L3`：能看懂 posterior、marginalization、latent distribution
- `L4`：能把论文方法抽象成随机变量与分布结构

## 模块 4：不等式、上界与优化直觉

### 为什么要学
这是研究中最容易“看着像玄学，其实全是基本功”的部分。

### 核心内容
- Jensen 不等式
- Cauchy-Schwarz
- Markov / Chebyshev 的直觉
- 上界 / 下界思想
- surrogate objective
- 为什么优化常常要换目标
- optimization 的三层视角：
  - 目标层
  - 几何层
  - 算法层

### 过关标准
- `L1`：看到 bound 不再完全发怵
- `L2`：能补出简单 upper bound 的关键步骤
- `L3`：能看出作者是在改原目标还是换 surrogate
- `L4`：能判断某个 bound 是否只是技巧，还是改变了问题本身

## 模块 5：常见训练目标与 divergence

### 为什么要学
很多训练论文表面不一样，本质上都在最小化某种 loss 或 divergence。

### 核心内容
- MSE
- cross-entropy
- negative log-likelihood
- KL divergence
- $\chi^2$ divergence 的直觉
- regularization
- constrained objective 的基本形式

### 过关标准
- `L1`：知道每种 loss 大概在干什么
- `L2`：会推最基础的 loss 梯度
- `L3`：能看懂论文为什么选择某种目标
- `L4`：能比较两个目标之间的优化含义和 inductive bias

## 模块 6：优化算法

### 为什么要学
同一个目标函数，不同优化方法可能训练体验完全不同。

### 核心内容
- Gradient Descent
- SGD
- mini-batch
- noise 的作用
- Momentum 的直觉
- Adam 的直觉
- learning rate 的作用
- 平坦区、陡峭区、条件数的基本直觉

### 过关标准
- `L1`：知道 SGD / Adam 是什么
- `L2`：能说清楚它们更新规则的大意
- `L3`：能解释为什么某些设置更稳 / 更快
- `L4`：能把训练现象翻译成优化几何问题

## 模块 7：采样、估计与 Monte Carlo

### 为什么要学
这是理解 sample efficiency、test-time compute、importance sampling、policy gradient 的底层工具。

### 核心内容
- estimator 是什么
- bias / variance
- importance sampling
- proposal distribution
- sample size 与误差缩放
- Monte Carlo 近似的基本直觉

### 过关标准
- `L1`：知道采样是在近似一个算不动的量
- `L2`：能解释 importance sampling 的基本形式
- `L3`：能看懂论文里“采样器质量决定效率”
- `L4`：能用 bias / variance 视角评价推理或训练方法

## 模块 8：信息论直觉

### 为什么要学
训练目标、表示学习、推理效率里经常会出现 entropy、information、compression 语言。

### 核心内容
- entropy
- cross-entropy
- mutual information 的直觉
- minimum-length coding 的直觉
- information bottleneck 的基本语言

### 过关标准
- `L1`：知道这些量在衡量什么
- `L2`：会做最基本的代数变形
- `L3`：能看懂为什么某些论文用信息论语言组织论证
- `L4`：能判断某个“信息解释”到底是严格推导还是类比

## 模块 9：latent variable 与概率图模型直觉

### 为什么要学
这块直接连接 reasoning、slow thinking、posterior、active inference、VAE、EM。

### 核心内容
- latent variable
- posterior
- marginalization
- graphical model 的基本语言
- HMM
- EM 的基本直觉
- latent explanation 是什么

### 过关标准
- `L1`：知道 observable 和 latent 的区别
- `L2`：会解释边缘化和后验
- `L3`：能读 latent reasoning / slow thinking 论文的基本推导
- `L4`：能把一个方法明确写成 latent variable problem

## 模块 10：policy gradient 与训练推导

### 为什么要学
这块连接 RLHF、reasoning training、探索 / 利用、以及很多现代训练论文。

### 核心内容
- log-derivative trick
- REINFORCE
- 为什么高概率样本不一定是高信息样本
- exploration vs exploitation 的基本直觉
- train sampler / inference sampler 的区别

### 过关标准
- `L1`：知道 policy gradient 在估计什么
- `L2`：能看懂最基础推导
- `L3`：能把训练目标和梯度估计误差连起来
- `L4`：能分析某种训练策略为什么容易 collapse 或低效

## 模块 11：测度论语言

### 为什么要学
不是为了炫技，而是因为很多更理论化的论文会用它保证定义严谨。

### 核心内容
- measure
- probability measure
- Borel set
- pushforward
- conditional measure
- Radon-Nikodym derivative
- disintegration theorem 的作用

### 过关标准
- `L1`：不再被这些词吓住
- `L2`：知道每个对象在干什么
- `L3`：能读懂理论论文的定义部分
- `L4`：能看出一个论证里哪些测度论步骤是关键

## 模块 12：研究型阅读能力

### 为什么要学
最后你要的不是“背知识点”，而是形成研究员的阅读和判断方式。

### 核心内容
- 区分定义、定理、推导、intuition
- 判断一个论证是严格证明还是 heuristic
- 把论文拆成：
  - 表示问题
  - 估计问题
  - 优化问题
- 把方法拆成：
  - 改目标
  - 改采样
  - 改模型
  - 改优化器

### 过关标准
- `L1`：能跟着读
- `L2`：能补主要中间步骤
- `L3`：能结构化拆论文
- `L4`：能提出自己的问题定义和判断

## 推荐学习顺序

如果按“最适合大模型研究”的顺序，我建议是：

### 第一层：先打地基
1. 模块 1：线性代数
2. 模块 2：多元微积分与梯度
3. 模块 3：概率基础
4. 模块 4：不等式、上界与优化直觉

### 第二层：进入训练与推理语言
5. 模块 5：常见目标与 divergence
6. 模块 6：优化算法
7. 模块 7：采样、估计与 Monte Carlo
8. 模块 8：信息论直觉

### 第三层：进入研究型主题
9. 模块 9：latent variable 与图模型
10. 模块 10：policy gradient 与训练推导
11. 模块 11：测度论语言
12. 模块 12：研究型阅读能力

## 你怎么知道自己学到哪了

最简单的做法是给自己做一个总表：

- 线性代数：`L3`
- 多元微积分：`L2`
- 概率：`L2`
- optimization 直觉：`L2`
- divergence：`L1`
- 采样与估计：`L1`
- latent variable：`L0`

这张表以后会比“我学到第几个月了”更有用，因为它直接反映你能不能读懂某类论文。

## 现在先做到什么程度就够了

如果你的近期目标是：

$$
\text{能比较顺地读大模型训练 / 推理论文}
$$

那么短期最重要的是把下面这些至少打到 `L2-L3`：
- 模块 1：线性代数
- 模块 2：多元微积分与梯度
- 模块 3：概率基础
- 模块 4：不等式、上界与 optimization 直觉
- 模块 5：常见目标与 divergence
- 模块 7：采样与估计

这几块一旦稳住，后面你读很多论文会轻松很多。
