# 45天计划｜第1周（2026-02-04 → 2026-02-10）

平均用时（建议）：**每天约 2.5 小时**（±1小时浮动都没关系；关键是“计时训练 + 复盘纠错”）

## 使用材料（本地）
- 题型结构/资料总览：`Language/French/DELF_B2/DELF B2（Tout public）题型结构与官方资料清单.md`
- 官方样题与音频：`Language/French/DELF_B2/official_samples/`

## 本周目标
- 完成 **样题 Exemple 1** 的听力/阅读/写作（至少各1次计时）  
- 完成 **口试 1 套题**（含30min准备 + 录音复盘）  
- 建立并维护 1 个“错因表”（听力/阅读/写作/口语各自的高频失分点）

- [ ] 10m：快速过一遍 `Language/French/DELF_B2/DELF B2（Tout public）题型结构与官方资料清单.md`

- [ ] 40m：建立“错因表”（四类即可：词汇不懂 / 连读没听出 / 逻辑没跟上 / 题干关键词漏抓），并写下本周3个最需要补的点

## D02 2026-02-05（Thu）听力精听 + 复述（≈2.5h）
- [ ] 25m：练习1（按题做一遍）  
  - `Language/French/DELF_B2/official_samples/delf-b2-tp-coll-exemple1-exercice1.mp3`
- [ ] 55m：对照文字稿精听 3 轮（听→对照→再听）  
  - `Language/French/DELF_B2/official_samples/delf-b2-tp-surveillant-coll-exemple1.pdf`
- [ ] 30m：复述训练（每段30–60秒，至少5段；录音也可）

## D03 2026-02-06（Fri）阅读计时 + 结构笔记（≈2.5h）
- [ ] 60m：阅读计时做题（Exemple 1 阅读部分）  
  - `Language/French/DELF_B2/official_samples/delf-b2-tp-candidat-coll-exemple1.pdf`

  - `Language/French/DELF_B2/official_samples/delf-b2-tp-correcteur-coll-exemple1.pdf`

## D04 2026-02-07（Sat）写作第1篇（严格计时）+ 精改（≈2.5h）
- [ ] 10m：分析题目（体裁/对象/目的/语域）
- [ ] 10m：列提纲（2–3论点 + 例子 + 让步/反驳）
- [ ] 60m：计时写作（≥250词）  
  - `Language/French/DELF_B2/official_samples/delf-b2-tp-candidat-coll-exemple1.pdf`
- [ ] 30m：自查清单（结构是否清晰、连接词是否足够、语法错误是否集中在某类）
- [ ] 40m：精改一遍（目标：至少修正10处错误 + 替换5处更高级表达）

## D05 2026-02-08（Sun）口试第1套（准备30m + 录音）+ 复盘（≈2.5h）
