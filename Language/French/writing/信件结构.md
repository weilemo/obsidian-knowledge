# Lettre formelle — 模板与万能句（DELF B2 写作）

适用：投诉/申请/建议/请求（正式语域、客观、礼貌）。  
核心要求：称呼与落款一致；按段落清晰组织；逻辑连接词到位。

## 0) 信件“骨架”（直接套用）
```
Monsieur/Madame …,

Introduction（身份 + 写信目的）

Développement（事实/影响 + 原因/对比 + 论证）

Propositions（1–3 条可执行的替代方案）

Conclusion（好处 + 请求行动 + 可联系）

Formule de politesse
Signature
```

## 1) 称呼（La formule d’appel）
- 必须正式，且与收件人的性别/职位一致。
- 不确定姓名：`Monsieur,` 或 `Madame,`
- 知道职位（推荐）：`Monsieur le Directeur,` / `Madame la Directrice,` / `Monsieur le Maire,` 等
- 注意：一般不要加姓氏（不要写 `Monsieur Fabre`），只写头衔或尊称。

## 2) 开头段：表明身份与目的（Introduction）
回答：我是谁？我为什么写这封信？

**表明身份**
- FR: En tant que [身份/职位], …  
  CN: 作为[身份/职位]，……
- FR: Je me permets de vous écrire en qualité de [职位] …  
  CN: 我以[职位]的身份冒昧给您写信……

**说明目的**
- FR: Je vous écris pour vous faire part de …  
  CN: 我写信是想告知您……
- FR: Par la présente, je souhaiterais attirer votre attention sur …  
  CN: 特此去函，想引起您对……的关注
- FR: J’ai l’honneur de solliciter votre attention concernant …  
  CN: 我很荣幸请您关注……（非常正式）
- FR: Permettez-moi de vous présenter une situation concernant …  
  CN: 请允许我向您介绍关于……的情况

exemple:
Habitant de notre ville depuis plusieurs années, j'ai appris avec beaucoup d'inquiétude que le cinema municipal risquait de fermer définitivement, en raison d'un manque de fréquentation et de moyens financiers.



## 3) 主体段落：阐述问题/论证（Développement）
信的核心：描述现状、分析原因、列举论据；务必用逻辑连接词。

**描述问题/现状**
- FR: Depuis quelques semaines, nous rencontrons des difficultés à …  
  CN: 几周以来，我们在……方面遇到了困难
- FR: J’ai constaté que …  
  CN: 我注意到……
- FR: Il est regrettable que …  
  CN: 很遗憾的是……

**分析原因/转折**
- FR: En effet, …  
  CN: 确实/事实上……（用来解释上一句）
- FR: Toutefois / Cependant, …  
  CN: 然而/不过……
- FR: Selon moi, ce problème est dû à …  
  CN: 在我看来，这个问题是由于……
- FR: Le problème réside dans le fait que …  
  CN: 问题在于……

**提出建议/解决方案**
- FR: C’est pourquoi je me permets de vous proposer de …  
  CN: 因此，我冒昧向您建议……
- FR: Je vous suggère donc de …  
  CN: 所以我建议您……
- FR: Une solution envisageable serait de …  
  CN: 一个可行的方案是……
- FR: Il serait judicieux de …  
  CN: ……是明智之举

## 4) 结尾段：强调利益与请求行动（Conclusion）
重申好处 + 请求对方采取行动/批准。

**强调好处**
- FR: Il ne fait aucun doute que cela aura des conséquences positives sur …  
  CN: 毫无疑问，这会对……产生积极影响
- FR: Cette initiative permettrait d’améliorer …  
  CN: 这一举措将有助于改善……

**期待/请求支持**
- FR: En espérant pouvoir compter sur votre soutien, …  
  CN: 希望能得到您的支持，……
- FR: Dans l’attente de votre réponse, …  
  CN: 期待您的回复，……
- FR: Je reste à votre entière disposition pour tout renseignement complémentaire.  
  CN: 如需补充信息，我随时愿意提供（加分句）

## 5) 落款致意（La formule de politesse）
通用、最保险（称呼必须前后一致；不要自造句）。

- FR: Je vous prie d’agréer, Monsieur le Directeur, l’expression de mes salutations distinguées.  
  CN: 请接受我最诚挚的问候（公函固定套语）

## 常用句（按“写什么信都好用”的功能）
### 反对/质疑决定（contester une décision）
- FR: Je me permets de contester la décision de ___.  
  CN: 我冒昧对___这一决定提出异议。
- FR: Nous souhaitons exprimer notre vive inquiétude concernant ___.  
  CN: 我们希望表达对___的强烈担忧。
- FR: Cette mesure risque de + infinitif / risque d’entraîner ___.  
  CN: 这一措施可能会……/可能会导致……
- FR: Nous vous demandons de bien vouloir reconsidérer ___.  
  CN: 我们恳请您重新考虑___。

### 描述事实（exposer la situation）
- FR: Depuis [date/période], nous constatons que ___.  
  CN: 自[时间]以来，我们注意到___。
- FR: Cette situation a des répercussions sur ___.  
  CN: 这种情况对___产生影响。

### 提建议（proposer des solutions）
- FR: Une solution envisageable consisterait à ___.  
  CN: 一个可行的方案是___。
- FR: Il serait souhaitable de ___ afin de ___.  
  CN: 最好___以便___。
- FR: Serait-il possible d’envisager ___ ?  
  CN: 是否可以考虑___？

### 请求回复/会面（demander un retour / un rendez-vous）
- FR: Je vous serais reconnaissant(e) de bien vouloir me faire part de votre position.  
  CN: 如您能告知您的意见，我将不胜感激。
- FR: Serait-il possible d’organiser un échange avec les riverains ?  
  CN: 是否可以安排一次与居民的沟通？

### 加分句（保持礼貌但坚定）
- FR: Nous comprenons les objectifs de cette mesure ; toutefois, ___.  
  CN: 我们理解该措施的目的；然而，___。
- FR: Il va de soi que ___ ; néanmoins, ___.  
  CN: 毫无疑问___；但___。
