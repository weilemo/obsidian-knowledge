# Grammaire — DELF B2 (Production écrite)

目标：收集“写作里最好用、最稳、最容易加分”的语法结构。每条尽量做到：**什么时候用** + **一句可套用模板** + **一个例句**。

## 使用方式（可持续积累）
- 写作前：从每个大类（时态/语态/从句）各挑 1–2 个结构，确保“多样性”但不冒险。
- 写作后：把你写错或不自然的句子，改成更稳的模板，追加到对应小节末尾。

## 时态搭配（Temps verbaux）

### Imparfait（未完成过去时）
**什么时候用**：过去的背景/习惯/持续状态；写叙事或举例时很加分（对比“以前 vs 现在”）。  
**模板**：
- `À l’époque, + imparfait`（当时……）
**例句**：À l’époque, on travaillait presque exclusivement au bureau.

### Conditionnel présent（现在条件式）
**什么时候用**：礼貌/建议、假设、缓和语气、表达“可能性/推测”（比肯定更像 B2 写作风格）。  
**模板**：
- `Il serait + adjectif + de + infinitif`（做……会更……）
- `On pourrait + infinitif`（我们可以……）
**例句**：Il serait pertinent d’encourager un modèle hybride.

## 动词变位速查（Conjugaison express）

### 1) Imparfait（未完成过去时）
**构成**：取 `nous` 现在时词干（去掉 `-ons`）+ 词尾  
`-ais, -ais, -ait, -ions, -iez, -aient`
- parler → je parlais
- finir → nous finissions
- prendre → ils prenaient
**常见不规则**：
- `être`：j’étais, tu étais, il/elle était, nous étions, vous étiez, ils/elles étaient

### 2) Passé composé（复合过去时）
**构成**：`avoir/être` 现在时 + 过去分词
- 多数动词用 `avoir`：j’ai parlé, nous avons fini
- 运动/状态变化类及所有代词式动词常用 `être`：je suis allé(e), elle s’est levée
**配合规则**：
- `avoir`：过去分词通常不配合；若直接宾语在前，需配合  
  例：Les lettres que j’ai écrites.
- `être`：与主语性数配合  
  例：Elles sont arrivées.
**常见不规则过去分词**：
- avoir → eu
- être → été
- faire → fait
- dire → dit
- écrire → écrit
- mettre → mis
- prendre → pris
- apprendre/comprendre → appris/compris
- voir → vu
- pouvoir → pu
- vouloir → voulu
- devoir → dû
- savoir → su
- boire → bu
- lire → lu
- croire → cru
- recevoir → reçu
- vivre → vécu
- venir → venu
- ouvrir → ouvert
- offrir → offert
- mourir → mort
- naître → né

### 3) Futur simple（简单将来时）
**构成**：不定式（`-re` 动词去 `e`）+ 词尾  
`-ai, -as, -a, -ons, -ez, -ont`
- parler → je parlerai
- finir → nous finirons
- prendre → ils prendront
**高频不规则词干**：
- être → ser- (je serai)
- avoir → aur- (j’aurai)
- aller → ir- (j’irai)
- faire → fer- (je ferai)
- venir → viendr- (je viendrai)
- voir → verr- (je verrai)
- pouvoir → pourr- (je pourrai)
- vouloir → voudr- (je voudrai)
- devoir → devr- (je devrai)
- savoir → saur- (je saurai)
- recevoir → recevr- (je recevrai)
- envoyer → enverr- (j’enverrai)

### 4) Subjonctif présent（虚拟式现在时）
**构成**：通常取 `ils` 现在时词干去 `-ent` + 词尾  
`-e, -es, -e, -ions, -iez, -ent`
- parler → que je parle
- finir → que nous finissions
**高频不规则**：
- être → que je sois, que nous soyons
- avoir → que j’aie, que nous ayons
- aller → que j’aille, que nous allions
- faire → que je fasse, que nous fassions
- pouvoir → que je puisse
- vouloir → que je veuille, que nous voulions
- savoir → que je sache
**常见触发结构**：
- il faut que…
- bien que…
- pour que / afin que…
- à condition que…

### 5) Conditionnel présent（现在条件式）
**构成**：`futur` 词干 + `imparfait` 词尾  
`-ais, -ais, -ait, -ions, -iez, -aient`
- parler → je parlerais
- finir → nous finirions
- prendre → ils prendraient
**不规则词干**：与 `futur simple` 基本相同  
（ser-, aur-, ir-, fer-, viendr-, voudr-, pourr-, devr-, saur-…）
**常见用法**：
- 礼貌：Je voudrais…
- 建议：On pourrait…
- 假设：Si + imparfait, conditionnel présent

### 6) Impératif（命令式）
**构成**：通常取现在时 `tu / nous / vous` 形式（不写主语）
- Parle ! / Parlons ! / Parlez !
- Finis ! / Finissons ! / Finissez !
**常见规则**：
- `-er` 动词 `tu` 形一般去掉词尾 `-s`：Parle ! Regarde !
- 但后接 `y/en` 时加回 `-s`：Vas-y ! Manges-en !
**常见不规则**：
- être → sois, soyons, soyez
- avoir → aie, ayons, ayez
- savoir → sache, sachons, sachez
- vouloir（少见，偏正式）→ veuille, veuillons, veuillez

### 7) Gérondif / Participe présent（现在分词）
**构成**：
- 现在分词：`nous` 词干（去 `-ons`）+ `-ant`
- 副动词：`en + 现在分词`
- 例：nous parlons → parlant；en parlant
**高频不规则现在分词**：
- être → étant
- avoir → ayant
- savoir → sachant
**常见用法**：
- 同时动作：Il écoute de la musique en travaillant.
- 方式手段：On apprend en pratiquant.

### 8) Participe passé（过去分词）
**常见规则**：
- `-er` → `-é`（parler → parlé）
- `-ir`（第二组）→ `-i`（finir → fini）
- `-re` → `-u`（attendre → attendu，vendre → vendu）
**高频不规则清单（写作最常用）**：
- être été, avoir eu, faire fait, dire dit
- mettre mis, prendre pris, apprendre appris
- voir vu, lire lu, boire bu, croire cru
- devoir dû, pouvoir pu, vouloir voulu, savoir su
- écrire écrit, conduire conduit, construire construit
- ouvrir ouvert, offrir offert, découvrir découvert
- venir venu, tenir tenu, revenir revenu
- naître né, mourir mort, vivre vécu, recevoir reçu

## 一页记忆法（考试前 5 分钟）
- 先背三套词尾：`imparfait`、`futur/conditionnel`、`subjonctif`
- 再背两套不规则词干：`futur/conditionnel` 词干、`subjonctif` 高频不规则
- 最后背一组高频过去分词（eu, été, fait, dit, mis, pris, vu, pu, voulu, dû, su, écrit, lu…）



## 语态（Voix）

### Voix passive（被动语态）
**什么时候用**：强调“动作承受者”或避免主语（更客观、偏书面）。  
**模板**：
- `être + participe passé + par`（被……）
**例句**：Ces mesures sont souvent perçues comme contraignantes par les consommateurs.
**注意**：被动别滥用；一篇作文 1–2 句足够。

### On（泛指主语）
**什么时候用**：表达“普遍现象/一般人”。比 “nous” 更中性。  
**模板**：
- `On constate que …`（人们发现/我们注意到……）
**例句**：On constate que les échanges informels disparaissent à distance.

### Administratif（更正式、更客观的写法）
**什么时候用**：正式信件/报告风格；避免“我/我们”过多，增加客观性。  
**模板**：
- `Il a été décidé que + indicatif`  
  CN: 已决定……（被动、官方语气）
- `Il a été annoncé que + indicatif`  
  CN: 已宣布……（新闻/公告语气）
**例句**：Il a été décidé que certaines rues seraient ouvertes aux autobus en journée.

## 易错清单（À vérifier avant de交卷）
- `bien que / afin que / pour que / à condition que` → 一般接 `subjonctif`
- `si` 后面一般不用 `conditionnel`（错误：*si je serais*）
- `malgré` + 名词；`bien que` + 从句
- `leur`（给他们）vs `leurs`（他们的 + 复数名词）
- 过去分词配合：`les mesures que j’ai prises`（与 `que` 指代的宾语一致）
