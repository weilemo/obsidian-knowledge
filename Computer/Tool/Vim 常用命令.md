# Vim 常用命令

## 进入与模式

| 命令 | 作用 |
|---|---|
| `vim file.md` | 打开文件 |
| `Esc` | 回到普通模式 |
| `i` | 在光标前插入 |
| `a` | 在光标后插入 |
| `I` | 行首插入 |
| `A` | 行尾插入 |
| `o` | 下一行新建并插入 |
| `O` | 上一行新建并插入 |
| `v` | 进入可视选择 |
| `V` | 按行选择 |

## 保存与退出

| 命令 | 作用 |
|---|---|
| `:w` | 保存 |
| `:q` | 退出 |
| `:wq` | 保存并退出 |
| `ZZ` | 保存并退出 |
| `:q!` | 不保存强制退出 |
| `:w file2.md` | 另存为 |

## 光标移动

| 命令 | 作用 |
|---|---|
| `h` `j` `k` `l` | 左、下、上、右 |
| `w` | 到下一个词开头 |
| `e` | 到当前或下一个词结尾 |
| `b` | 到上一个词开头 |
| `0` | 到行首 |
| `^` | 到本行第一个非空字符 |
| `$` | 到行尾 |
| `gg` | 到文件开头 |
| `G` | 到文件结尾 |
| `12G` | 跳到第 12 行 |
| `Ctrl-f` | 向下翻页 |
| `Ctrl-b` | 向上翻页 |
| `%` | 在括号、引号等匹配符之间跳转 |

## 编辑文本

| 命令 | 作用 |
|---|---|
| `x` | 删除当前字符 |
| `dd` | 删除当前行 |
| `3dd` | 删除 3 行 |
| `yy` | 复制当前行 |
| `3yy` | 复制 3 行 |
| `p` | 粘贴到光标后或下一行 |
| `P` | 粘贴到光标前或上一行 |
| `u` | 撤销 |
| `Ctrl-r` | 重做 |
| `rX` | 将当前字符替换为 `X` |
| `cw` | 修改当前词 |
| `ciw` | 修改光标所在整个词 |
| `C` | 修改到行尾 |
| `D` | 删除到行尾 |
| `J` | 合并下一行 |

## 搜索与替换

| 命令 | 作用 |
|---|---|
| `/keyword` | 向下搜索 |
| `?keyword` | 向上搜索 |
| `n` | 下一个匹配 |
| `N` | 上一个匹配 |
| `*` | 搜索光标所在词 |
| `:%s/old/new/g` | 全文替换 |
| `:%s/old/new/gc` | 全文替换，并逐个确认 |
| `:10,20s/old/new/g` | 只替换第 10 到 20 行 |

## 选择与缩进

| 命令 | 作用 |
|---|---|
| `v` 后移动 | 按字符选择 |
| `V` 后移动 | 按行选择 |
| `>` | 右缩进选择内容 |
| `<` | 左缩进选择内容 |
| `=` | 自动缩进选择内容 |
| `gg=G` | 全文自动缩进 |

## 文件、窗口、缓冲区

| 命令 | 作用 |
|---|---|
| `:e file.md` | 打开另一个文件 |
| `:bn` | 下一个缓冲区 |
| `:bp` | 上一个缓冲区 |
| `:bd` | 关闭当前缓冲区 |
| `:split file.md` | 水平分屏 |
| `:vsplit file.md` | 垂直分屏 |
| `Ctrl-w h/j/k/l` | 在窗口间移动 |
| `Ctrl-w c` | 关闭当前窗口 |
| `Ctrl-w =` | 平均分配窗口大小 |

## 常用组合

| 目标 | 命令 |
|---|---|
| 打开文件后编辑 | `vim file.md` -> `i` |
| 保存退出 | `Esc` -> `:wq` |
| 不保存退出 | `Esc` -> `:q!` |
| 删除一行并粘贴到别处 | `dd` -> 移动光标 -> `p` |
| 复制一行并粘贴到别处 | `yy` -> 移动光标 -> `p` |
| 搜索后逐个查看 | `/keyword` -> `n` / `N` |
| 全文替换并确认 | `:%s/old/new/gc` |

## 记忆规则

- 普通模式负责移动和命令，插入模式负责输入文字。
- 大多数命令可以加数字前缀，例如 `5j` 向下 5 行，`3dd` 删除 3 行。
- `d` 是删除，`y` 是复制，`c` 是修改；它们可以和移动命令组合，例如 `dw` 删除一个词，`d$` 删除到行尾。
