# 学习路线图（30天）

## 第1周：大模型全景
- 目标：建立 SFT / DPO / RLHF / RLVR 的关系图。
- 产出：一页对比表 + 一页你自己的训练流程图。

## 第2周：Agent 架构
- 目标：搞清 Planner / Executor / Tool / Memory / Env 的职责边界。
- 产出：一个可运行的最小 Agent 工作流图。

## 第3周：Agentic RL
- 目标：理解 MDP、长程 credit assignment、trajectory 级稳定性。
- 产出：一份“训练崩溃排查清单”。

## 第4周：系统化落地
- 目标：掌握异步 rollout、监控、回滚、评估闭环。
- 产出：你的端到端训练与评估 SOP。
