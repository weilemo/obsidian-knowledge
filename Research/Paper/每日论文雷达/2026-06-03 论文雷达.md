## MLLM / Multimodal Large Language Model / Vision-Language Model

### 1. PaCo-VLA: Passivity-Shielded Compliance Prior for Contact-Rich Vision-Language-Action Manipulation

- 作者/机构：Haofan Cao, Zhaoyang Li, Zhichao You, Liang Guo, Tianrui Li
- 日期：2026-05-30
- 链接：[arXiv:2606.00515](https://arxiv.org/abs/2606.00515)
- 中文摘要：这篇工作不是把 VLA 直接下放到底层控制，而是把模型输出改造成“任务级 compliance proposal”，再由一个高频 passivity shield 做能量约束与边界检查。核心贡献是把语义层泛化能力和接触控制安全性解耦，减少 foundation model 在高频接触操作中的失控风险。
- 为什么值得关注：VLA 研究最近的瓶颈不只是“会不会做”，而是“能不能安全接管真实控制回路”。这篇工作给出了一个很工程化、也很可能被后续系统复用的 runtime contract。
- 与用户研究方向的关系：如果你关心 agent 从“会调用工具”走向“能与真实环境稳定闭环”，这类把模型能力包进受约束执行层的设计，和 coding agent 中 harness / sandbox / verifier 的作用在结构上是同类问题。
