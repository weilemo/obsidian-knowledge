## Coding Agent / Software Engineering Agent / SWE-bench

### 1. Skill Availability and Presentation Granularity in Large-Language-Model Agents: A Controlled SkillsBench Study

- 作者/机构：Xiaonan Xu, Wenjing Wu
- 日期：2026-05-29
- 链接：[arXiv:2605.31408](https://arxiv.org/abs/2605.31408)
- 中文摘要：这篇工作在受控的 SkillsBench 子集上，系统比较了“是否给 agent 提供技能文档”以及“技能文档写得更抽象还是更具体”对任务成功率的影响。结果显示，真正显著的增益来自“有技能可用”本身，而不同呈现粒度之间的差异较小、而且依模型而变。
- 为什么值得关注：它把很多工程直觉量化了。相比继续争论 prompt 应该写长写短，这篇更重要的结论是 agent 的外部技能资产本身才是主要杠杆。
- 与用户研究方向的关系：这和你关心的 coding agent / software engineering agent 非常贴近，尤其适合拿来校准“agent memory / skill system 到底值不值得做结构化投入”。

### 2. Learning Agent-Compatible Context Management for Long-Horizon Tasks

- 作者/机构：Lu Yi, Runlin Lei, Liuyi Yao, Yuexiang Xie, Yuyang Li, Wenhao Zhang, Zhewei Wei, Yaliang Li, Jian-Yun Nie
- 日期：2026-05-28
- 链接：[arXiv:2605.30785](https://arxiv.org/abs/2605.30785)
- 中文摘要：论文聚焦长时程 agent 在真实任务里常见的上下文爆炸问题，核心目标不是简单摘要历史，而是学习一种更“agent-compatible”的上下文管理方式，使模型在 web search / deep research 一类任务中能持续保留关键状态并避免长上下文退化。
- 为什么值得关注：这正打在实用 agent 的瓶颈上。很多 agent 失败并不是不会推理，而是随着轨迹拉长，工作记忆和上下文选择开始系统性崩掉。
- 与用户研究方向的关系：这篇同时连接 `coding/search agent` 和 `agent memory`，适合作为你后续看长期记忆、上下文压缩、过程监督时的桥梁论文。

## MLLM / Multimodal LLM / Vision-Language Model

### 1. VisionPulse: Dynamic Visual Sparsity for Efficient Multimodal Reasoning

- 作者/机构：Hengbo Xu, Shengjie Jin, Yanbiao Ma, Zhiwu Lu
- 日期：2026-05-29
- 链接：[arXiv:2605.31457](https://arxiv.org/abs/2605.31457)
- 中文摘要：这篇工作研究多模态推理时的视觉 token 冗余问题，指出真正关键的视觉证据会随着解码步骤变化。VisionPulse 在推理过程中动态裁剪视觉 token，每步只保留小部分高价值视觉信息，在几乎不掉精度的前提下显著减少视觉开销并缩短推理轨迹。
- 为什么值得关注：这不是静态 prefill 剪枝，而是把“视觉证据是随推理阶段流动的”这个观点做成了在线机制。对部署型 MLLM 来说，这比单纯加大模型更有现实价值。
- 与用户研究方向的关系：如果你关注 MLLM 的效率和真实 agent 场景可用性，这篇属于很值得盯的 inference-time 系统论文。

### 2. Qwen-VLA: Unifying Vision-Language-Action Modeling across Tasks, Environments, and Robot Embodiments

- 作者/机构：Qiuyue Wang 等，Qwen / Alibaba 团队
- 日期：2026-05-28
- 链接：[arXiv:2605.30280](https://arxiv.org/abs/2605.30280)
- 中文摘要：Qwen-VLA 试图把 manipulation、navigation、trajectory prediction 等具身任务统一到单一 vision-language-action 框架里，用共享主干和动作解码器处理跨环境、跨任务、跨机器人本体的连续控制。论文展示了统一训练后在多个 benchmark 上的稳定表现和跨平台泛化。
- 为什么值得关注：它代表了 `VLM -> VLA` 的继续推进，重点已经不只是“能看懂图像”，而是“能否在不同 embodiment 上复用理解与行动表征”。
- 与用户研究方向的关系：你关心的 `MLLM + agent` 主线如果继续往真实交互和行动闭环推进，Qwen-VLA 是近 7 天里最值得保留的代表作之一。

### 3. LoMo: Local Modality Substitution for Deeper Vision-Language Fusion

- 作者/机构：Feng Han, Zhixiong Zhang, Zheming Liang, Yibin Wang, Jiaqi Wang；Fudan University
- 日期：2026-05-28
- 链接：[arXiv:2605.30265](https://arxiv.org/abs/2605.30265)
- 中文摘要：LoMo 关注 VLM 的模态敏感性偏差，指出同样语义如果换一种模态载体，模型表现可能显著波动。作者通过局部模态替换的数据构造方式，增强跨模态表示对语义的一致性，从而改善融合与推理。
- 为什么值得关注：它不是继续堆结构，而是对一个很基础的问题开刀: 模型到底学到的是“语义”，还是特定模态下的表面模式。
- 与用户研究方向的关系：对后续研究 multimodal reasoning、视觉 grounding、以及多模态 agent perception 都很有参考价值。

## RLHF / RLAIF / GRPO / RL for LLM

### 1. LongTraceRL: Learning Long-Context Reasoning from Search Agent Trajectories with Rubric Rewards

- 作者/机构：Nianyi Lin, Jiajie Zhang, Lei Hou, Juanzi Li；Tsinghua University Knowledge Engineering Group
- 日期：2026-05-29
- 链接：[arXiv:2605.31584](https://arxiv.org/abs/2605.31584)
- 中文摘要：LongTraceRL 面向长上下文推理，利用 search agent 的真实轨迹构造分层干扰文档，并用基于 gold reasoning chain 的 rubric reward 提供细粒度过程监督。相较只看最终答案的稀疏奖励，它更强调中间推理过程是否真的抓住了关键实体与证据链。
- 为什么值得关注：这篇把 `agent trajectory -> RL data` 的闭环做得很漂亮，尤其适合长文档检索与深度研究场景。干扰项构造和 process reward 设计都很有复用价值。
- 与用户研究方向的关系：它同时命中 `RL for LLM`、`search/coding agent`、`long-context reasoning` 三条线，是本轮最接近你主线交叉点的论文之一。

### 2. Consolidating Rewarded Perturbations for LLM Post-Training

- 作者/机构：Zheyu Zhang, Shuo Yang, Gjergji Kasneci
- 日期：2026-05-29
- 链接：[arXiv:2605.31494](https://arxiv.org/abs/2605.31494)
- 中文摘要：论文观察到基于奖励的权重扰动后训练方法里，好的扰动方向并不是完全随机，而是存在可复用的低秩结构。作者据此提出 CoRP，在不让梯度穿过语言模型的情况下，把多次 rewarded perturbation 的收益压缩进单个可部署模型。
- 为什么值得关注：它把“需要大量采样或集成才能拿到的 post-training 增益”往单模型部署方向压缩，兼顾训练开销和上线成本。
- 与用户研究方向的关系：如果你在看 RLHF / RLVR / post-training recipe，这篇对“如何把 reward-driven search 变成可交付模型”很有启发。

## Agent Memory / Long-term Memory for LLM Agents

### 1. AutoSci: A Memory-Centric Agentic System for the Full Scientific Research Lifecycle

- 作者/机构：Weitong Qian 等
- 日期：2026-05-29
- 链接：[arXiv:2605.31468](https://arxiv.org/abs/2605.31468)
- 中文摘要：AutoSci 试图把科研 agent 做成一个全生命周期系统，覆盖读文献、想法管理、实验、写作和 rebuttal，并把 persistent memory 放在系统中心。它将长期可复用知识和项目级活动记忆分开，再配合流程编排、DAG 化多 agent 操作符和演化机制持续改进。
- 为什么值得关注：这不是单点工具，而是把 `memory + workflow + self-evolution` 当成统一系统设计问题。对于长期任务型 agent，这是更像“操作系统”而不是单个 prompt 的方向。
- 与用户研究方向的关系：这篇和你关注的 `agent memory`、`coding/research agent`、`长期复利式能力积累` 高度一致，值得后续单独扩成论文卡。

### 2. Beyond Static Dialogues: Benchmarking Realistic, Heterogeneous, and Evolving Long-Term Memory

- 作者/机构：Han Zhang, Zihao Tang, Xin Yu, Xiao Liu, Yeyun Gong, Haizhen Huang, Yan Lu, Weiwei Deng, Feng Sun, Qi Zhang, Hanfang Yang
- 日期：2026-05-29
- 链接：[arXiv:2605.31086](https://arxiv.org/abs/2605.31086)
- 中文摘要：这篇工作指出现有 memory benchmark 的对话往往太静态、人格太平、外部信息源也太单一，因此无法逼真评估长期记忆能力。作者提出 RHELM，把动态演化的人物设定、异构外部数据源和长程事件轨迹结合起来，构造更接近真实用户世界的记忆评测。
- 为什么值得关注：做 memory 系统不能只看“能不能记住一句话”，而要看跨时间、跨来源、跨事件的整合与更新。这个 benchmark 正在把评测标准往真实场景推进。
- 与用户研究方向的关系：如果你后面要判断 memory system 的有效性，这篇比很多旧 benchmark 更接近真正需要的评测形态。
