# 稀疏注意力研究地图与经典论文综述

## 0. 一句话定义
稀疏注意力（Sparse Attention）是在注意力矩阵上显式施加结构约束，让每个 token 只与少量关键 token 交互，从而把标准自注意力的二次复杂度压到近线性或次二次。

## 1. 问题背景与统一数学视角
标准自注意力为：

$$
\mathrm{Attn}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^\top}{\sqrt{d}}\right)V
$$

当序列长度为 $n$ 时，注意力计算和显存通常是 $O(n^2)$ 量级。稀疏注意力用掩码矩阵 $M\in\{0,1\}^{n\times n}$ 约束连接关系：

$$
\alpha_{ij}=0\quad\text{if}\quad M_{ij}=0
$$

对第 $i$ 个 token，记可见邻居集合为 $\mathcal{N}(i)=\{j\mid M_{ij}=1\}$，则

$$
y_i=\sum_{j\in\mathcal{N}(i)}\frac{\exp(q_i^\top k_j/\sqrt{d})}{\sum_{t\in\mathcal{N}(i)}\exp(q_i^\top k_t/\sqrt{d})}v_j
$$

若平均每个 token 仅连接 $k$ 个邻居，复杂度可近似写为：

$$
\text{Time/Memory}\approx O(nk),\quad k\ll n
$$

## 2. 研究主线地图（按稀疏机制划分）

### A. 固定模式稀疏（Fixed Pattern）
核心思路：预先定义局部窗口、跨步、全局锚点等拓扑，训练和推理阶段结构稳定，工程实现最直接。

代表论文：
- [Image Transformer](https://arxiv.org/abs/1802.05751) (2018)：局部 self-attention 的早期代表，证明局部注意力可扩展到图像生成。
- [Generating Long Sequences with Sparse Transformers](https://arxiv.org/abs/1904.10509) (2019)：提出分解式稀疏模式（如 strided/fixed），经典里程碑。
- [Longformer](https://arxiv.org/abs/2004.05150) (2020)：滑窗 + 全局 token，成为长文档 NLP 的事实基线之一。
- [ETC](https://arxiv.org/abs/2004.08483) (2020)：局部 token 与全局 token 解耦，强调结构化输入。
- [Big Bird](https://arxiv.org/abs/2007.14062) (2020)：局部 + 随机 + 全局混合稀疏，理论与实证影响都很大。
- [Swin Transformer](https://arxiv.org/abs/2103.14030) (2021)：窗口注意力 + shifted window，在视觉领域形成强范式。
- [LongNet](https://arxiv.org/abs/2307.02486) (2023)：膨胀式注意力（dilated attention）扩展超长上下文。

### B. 内容自适应稀疏（Content-Adaptive）
核心思路：连接关系由内容动态决定，理论上更“聪明”，但通常引入额外路由或排序开销。

代表论文：
- [Reformer: The Efficient Transformer](https://arxiv.org/abs/2001.04451) (2020)：LSH attention，把相似 token 聚到同桶内计算。
- [Sparse Sinkhorn Attention](https://arxiv.org/abs/2002.11296) (2020)：可微排序/置换思想做块稀疏匹配。
- [Efficient Content-Based Sparse Attention with Routing Transformers](https://arxiv.org/abs/2003.05997) (2020)：在线聚类路由，兼顾内容自适应与稀疏化。
- [SparQ Attention](https://arxiv.org/abs/2312.04985) (2023)：通过少量特征维度先粗筛候选历史位置，重点优化带宽与缓存抓取。
- [IceFormer](https://arxiv.org/abs/2405.02842) (2024)：面向 CPU 推理，利用 attention 稀疏性加速长序列 Transformer。
- [Quest](https://arxiv.org/abs/2406.10774) (2024)：按 query 动态选择关键 KV pages，只对 top-k 页做精确 attention。

### C. 任务特化稀疏（Task-Specific）
核心思路：针对特定场景（时序预测/跨模态）定制稀疏策略，常与任务先验强耦合。

代表论文：
- [Informer: Beyond Efficient Transformer for Long Sequence Time-Series Forecasting](https://arxiv.org/abs/2012.07436) (2020)：提出 ProbSparse，在长序列时序预测很有代表性。
- [Long-Short Transformer: Efficient Transformers for Language and Vision](https://arxiv.org/abs/2107.02192) (2021)：将短程与长程依赖拆分建模。
- [Star-Transformer](https://arxiv.org/abs/1902.09113) (2019)：星形拓扑（relay + satellite）降低全连接开销。

## 3. 时间线（经典脉络）
- 2018-2019：从“局部注意力可行”走向“显式稀疏拓扑”（Image Transformer, Sparse Transformer）。
- 2020：高峰期，三条路线同时成熟：固定稀疏（Longformer/BigBird/ETC）、动态稀疏（Reformer/Routing/Sinkhorn）、任务稀疏（Informer）。
- 2021-2023：向视觉和超长上下文扩展（Swin、LongNet），并与系统优化深度耦合。

## 4. 经典论文阅读路径（建议）
如果目标是“快速形成科研地图”，建议按下面顺序读：

1. 稀疏拓扑起点：
   - Sparse Transformer (2019)
2. 动态路由代表：
   - Reformer (2020)
   - Routing Transformer (2020)
3. 长文本三件套：
   - Longformer (2020)
   - ETC (2020)
   - BigBird (2020)
4. 跨领域扩展：
   - Informer (时序)
   - Swin (视觉)
   - LongNet (超长上下文)

## 5. 论文对比时建议统一的评估维度
做论文横向对比时，建议固定以下维度：

- 稀疏类型：固定 / 动态 / 混合。
- 每 token 平均连接数：$k$ 随 $n$ 是否增长。
- 索引构建开销：是否需要哈希、聚类、排序。
- 训练-推理一致性：mask 是否一致，是否存在分布偏移。
- 长程信息路径长度：最远 token 间最短路径是否过长。
- 硬件友好性：是否能高效映射到 GPU 内核（尤其是块稀疏）。

## 6. 地图式结论（给你后续选题用）
- 固定稀疏路线胜在稳定和易实现，是“工程落地优先”时的默认选择。
- 动态稀疏路线胜在自适应表达能力，但常见瓶颈是路由开销和并行效率。
- 2024 以后很多“长上下文工作”未必显式叫 sparse attention，但本质上仍在做“选择性连接 + 系统优化”。
- 若你后续做 VideoGen/Streaming，建议优先关注“块稀疏 + 缓存复用 + 因果结构”的组合，而非单点稀疏技巧。
