# Agent Foresight-研究地图

## 主题定义
该主题聚焦：
- agent 是否知道何时调用 world model；
- agent 是否能把 simulation 结果解释成有用证据；
- agent 是否能把 foresight 稳定整合进后续决策，而不是陷入过度规划、误读或确认偏误。

## 分类理由
- 该方向研究的核心不是提升 world model 本身的生成质量，而是分析 agent 与 world model 的交互治理问题。
- 它和 `SlowThinking` 的理论统一主线不同，也不属于 `VideoGen` 对生成器本体的研究，因此单独抽出 `AgentForesight` 更利于后续持续收录。
