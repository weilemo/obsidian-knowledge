# 语音生成大模型研究历程与豆包技术路线

## 0. 一句话结论
语音生成大模型大致经历了四次范式切换：`WaveNet 声码器时代 -> Tacotron/FastSpeech 端到端 TTS -> AudioLM/VALL-E 的 codec token 语言模型 -> diffusion/flow/speech LLM 的统一生成框架`。  
截至 `2026-04-29`，豆包公开资料显示，其“语音生成底座”核心对应 [[Seed-TTS: A Family of High-Quality Versatile Speech Generation Models]] 这条 `speech tokenizer + token LM + diffusion model + vocoder` 的混合路线；而豆包实时语音对话能力已升级到 `Seeduplex` 这种原生端到端全双工 speech LLM 路线，而不是传统 `ASR -> LLM -> TTS` 纯级联。

## 1. 研究历程主线

### A. Waveform / Neural Vocoder 前史
这一阶段的重点是“怎么把语音合成得更像真人”，核心突破主要发生在声码器侧。

- [WaveNet: A Generative Model for Raw Audio](https://arxiv.org/abs/1609.03499) (2016)
  - 代表意义：直接对原始波形做自回归建模，首次把神经生成语音自然度显著推高。
  - 局限：推理慢，工程成本高，更像“高质量声码器底座”而不是完整大模型体系。

### B. 端到端 TTS 成熟期
这一阶段从文本直接生成梅尔频谱或语音特征，再接声码器，形成现代 TTS 工业主线。

- [Tacotron: Towards End-to-End Speech Synthesis](https://arxiv.org/abs/1703.10135) (2017)
  - 代表意义：把文本到语音的多个模块整合成端到端序列到序列系统。
- [Natural TTS Synthesis by Conditioning WaveNet on Mel Spectrogram Predictions](https://arxiv.org/abs/1712.05884) (2017, Tacotron 2)
  - 代表意义：`文本 -> mel -> WaveNet` 两阶段路线成为经典范式。
- [FastSpeech: Fast, Robust and Controllable Text to Speech](https://arxiv.org/abs/1905.09263) (2019)
  - 代表意义：并行生成，显著改善推理速度、漏词和重复问题。
- [Conditional Variational Autoencoder with Adversarial Learning for End-to-End Text-to-Speech](https://arxiv.org/abs/2106.06103) (2021, VITS)
  - 代表意义：把 VAE、flow、GAN 融合到一阶段端到端 TTS，兼顾自然度和效率。

### C. Codec Token / Audio Language Model 崛起
这一阶段的核心转变是：不再把 TTS 看成连续信号回归，而是把语音离散成 token，再像语言模型一样做序列建模。

- [AudioLM: a Language Modeling Approach to Audio Generation](https://arxiv.org/abs/2209.03143) (2022)
  - 代表意义：证明音频可以像文本一样，在离散 token 空间里做长程一致建模。
- [Neural Codec Language Models are Zero-Shot Text to Speech Synthesizers](https://arxiv.org/abs/2301.02111) (2023, VALL-E)
  - 代表意义：把 TTS 明确表述为 neural codec token 的条件语言建模，推动零样本音色复刻成为主流方向。
  - 关键词：`neural codec`、`in-context learning`、`3 秒提示音`、`zero-shot voice cloning`。

### D. Diffusion / Flow / Speech LLM 统一阶段
这一阶段的目标不只是“把一句话念出来”，而是把语音生成、音色复刻、编辑、情绪控制、实时交互统一到更大的生成框架里。

- [NaturalSpeech 2: Latent Diffusion Models are Natural and Zero-Shot Speech and Singing Synthesizers](https://arxiv.org/abs/2304.09116) (2023)
  - 代表意义：用 latent diffusion 替代纯自回归 codec LM，改善韵律稳定性与自然度。
- [Voicebox: Text-Guided Multilingual Universal Speech Generation at Scale](https://arxiv.org/abs/2306.15687) (2023)
  - 代表意义：用 flow matching 做多任务统一语音生成，强调泛化和更快推理。
- [E2 TTS: Embarrassingly Easy Fully Non-Autoregressive Zero-Shot TTS](https://arxiv.org/abs/2406.18009) (2024)
  - 代表意义：把 fully non-autoregressive 零样本 TTS 做得非常简洁，说明复杂对齐模块并非唯一道路。
- [DiTAR: Diffusion Transformer Autoregressive Modeling for Speech Generation](https://arxiv.org/abs/2502.03930) (2025)
  - 代表意义：把自回归 LM 和 diffusion transformer 混合，用于连续语音表示生成，是字节在语音生成方向上的后续延展。

## 2. 豆包公开技术路线

### 2.1 语音生成底座：Seed-TTS
- [Seed-TTS: A Family of High-Quality Versatile Speech Generation Models](https://arxiv.org/abs/2406.02430)  
  提交日期：`2024-06-04`

公开摘要给出的核心结构是：

- `speech tokenizer`
- `token language model`
- `token diffusion model`
- `acoustic vocoder`

这意味着 Seed-TTS 不是纯粹的 VALL-E 式单段 codec LM，也不是纯粹的 diffusion-only 模型，而是混合路线：

- 先把参考语音转成 token
- 用自回归 token LM 结合文本和参考语音去生成目标语音 token
- 再用 diffusion transformer 补足细粒度声学细节
- 最后由 vocoder 还原波形

从公开论文看，Seed-TTS 的几个关键词是：

- 大规模预训练
- zero-shot speech in-context learning
- speaker fine-tuning
- emotion / style controllability
- self-distillation 做 timbre disentanglement
- RL post-training 提升鲁棒性、相似度和可控性

论文还公开了一个非自回归扩展：

- `Seed-TTS_DiT`
  - fully diffusion-based
  - 不依赖预估 phoneme duration
  - 支持 end-to-end speech generation 与 speech editing

### 2.2 豆包实时语音：从半双工端到端到全双工 speech LLM

### 2025-01-20：豆包实时语音大模型
- 官方页面：[豆包实时语音大模型](https://seed.bytedance.com/zh/realtime_voice)
- 关键信息：
  - 使用“原生方法深度融合语音与文本模态”
  - 是“真正意义上的端到端语音对话模型”
  - 强调超低时延、真人级语音表现、多模态 I/O、可打断
  - 页面现已明确标注“模型已升级至 Seeduplex”

这一步说明豆包的在线语音对话已经不是传统模块级拼接，而是在朝“原生 speech model”推进。

### 2026-04-09：Seeduplex 全双工语音大模型
- 官方页面：[Seed 全双工语音大模型发布：懂倾听、抗干扰，走向更自然的交互](https://seed.bytedance.com/zh/blog/introducing-seed-full-duplex-speech-llm-attentive-listening-robust-interference-suppression-enabling-more-natural-interaction)
- 关键信息：
  - 相比上一代“半双工豆包端到端语音模型”，Seeduplex 改为原生全双工框架
  - 核心能力是“边听边说”
  - 具备语音语义联合建模能力
  - 重点优化抗干扰、动态判停、打断响应、低时延
  - 工程侧公开提到投机采样、量化、稳定性优化

因此，如果问“豆包现在用什么方法”，更准确的回答应该分两层：

- 做语音合成、音色复刻、情绪可控时，公开底座主要对应 `Seed-TTS` 这条混合生成路线。
- 做实时语音对话时，公开产品路线已经升级到 `Seeduplex` 这种原生端到端全双工 speech LLM。

## 4. 建议阅读顺序
如果目标是快速形成“语音生成大模型研究地图”，建议顺序如下：

1. 先看 `WaveNet -> Tacotron -> Tacotron 2`
   - 建立“神经声码器 + 端到端 TTS”的基础范式。
2. 再看 `FastSpeech -> VITS`
   - 理解工业界为什么会追求并行化、稳定性和一阶段训练。
3. 再看 `AudioLM -> VALL-E`
   - 理解“speech token language modeling”为什么成为大模型拐点。
4. 最后看 `NaturalSpeech 2 / Voicebox / Seed-TTS / DiTAR`
   - 理解 diffusion、flow matching、hybrid speech generation、speech LLM 的最新路线。

## 5. 地图式结论
- 从长期趋势看，语音生成已经从“任务专用 TTS 模型”走向“具备泛化和上下文学习能力的 speech foundation model”。
- 豆包公开路线并不是单点押注某一种方法，而是在 `token LM`、`diffusion`、`RL post-training`、`real-time speech interaction` 上同时推进。
- 若你后续继续拆笔记，最值得单独展开的主题有三组：
  - `codec token 路线`：AudioLM、VALL-E、Seed-TTS
  - `diffusion / flow 路线`：NaturalSpeech 2、Voicebox、E2 TTS、DiTAR
  - `speech interaction 路线`：豆包实时语音、Seeduplex、端到端 speech-to-speech / full-duplex
