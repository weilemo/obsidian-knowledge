# Memory Matters: The Need to Improve Long-Term Memory in LLM-Agents

## 定位

这是一篇短综述，适合建立 memory vocabulary。直接 PDF 下载被站点拦截，所以此处保留官方 PDF 链接而不写本地附件。

## 读这篇要抓什么

- 长期记忆为什么是 LLM agent 的关键短板。
- 向量数据库式 memory 的能力边界。
- episodic memory、semantic memory、procedural memory 的区分。
- metadata、memory lifecycle、external knowledge integration 等开放问题。

## 对你的主线的价值

你可以用它来给 coding memory 分类：issue trajectory 属于 episodic，repo/API 知识属于 semantic，调试套路和命令序列属于 procedural。

## 分类判断

放在 `AgentMemory/20_长期记忆架构`，因为它提供长期记忆的分类框架。
