# LongVideo KVCache Quant 项目文档

## 项目目标
目标是围绕“长视频自回归生成中的 KV cache 量化”建立一条清晰研究线：
- 找到适合作为实验母体的 forcing-based 长视频生成基线；
- 评估 LLM 的通用 KV 量化方法能否直接迁移到长视频 AR diffusion；
- 进一步探索视频专用、结构感知、角色感知的 KV 量化方案。

一个更具体的项目目标可以写成：
$$
\min \ \text{KV Memory} + \alpha \cdot \text{Latency}
\quad
\text{s.t.}
\quad
\Delta \text{Video Quality} \le \epsilon
$$

## 研究问题
这个项目主要回答四个问题：
- 长视频生成里的 KV cache 误差累积，是否比 LLM 长上下文推理更敏感？
- 通用 KV 量化方法在视频生成里失效时，主要是坏在 identity、motion，还是 scene consistency？
- forcing 系列方法里不同历史角色是否需要不同量化精度？
- 视频专用量化是应该按 `layer/head/token` 分配精度，还是按 `sink/history/tail` 这种时间角色分配精度？

## 相关论文与入口

### 一、长视频 forcing / KV memory 基线
这些论文不是量化方法本身，但决定了你后续到底量化什么缓存、在哪个 rollout 框架下量化。

- [[Self-Forcing ✅]]
  - 论文链接: [arXiv:2506.08009](https://arxiv.org/abs/2506.08009)
  - 作用: 作为最基础的 forcing-based AR 长视频生成母体。
- [[Rolling-Forcing✅]]
  - 论文链接: [arXiv:2509.25161](https://arxiv.org/abs/2509.25161)
  - 作用: 更偏实时流式系统，是强基线之一。
- [[Deep-Forcing✅]]
  - 论文链接: [arXiv:2512.05081](https://arxiv.org/abs/2512.05081)
  - 作用: 直接讨论视频生成中的 KV cache 管理，和后续“量化 + 压缩联合设计”关系很近。
- [[Relax-Forcing]]
  - 论文链接: [arXiv:2603.21366](https://arxiv.org/abs/2603.21366)
  - 作用: 把时间记忆拆成 `Sink / History / Tail` 三种功能角色，非常适合作为角色感知量化的结构参考。

### 二、视频生成 / 视频模型专用 KV 量化
这部分是和项目最直接相关的核心论文。

- Quant VideoGen: Auto-Regressive Long Video Generation via 2-Bit KV-Cache Quantization
  - 论文链接: [arXiv:2602.02958](https://arxiv.org/abs/2602.02958)
  - 备注: 当前最应该优先吃透的“视频生成专用 KV 量化”论文。
- Plug-and-Play 1.x-Bit KV Cache Quantization for Video Large Language Models
  - 论文链接: [arXiv:2503.16257](https://arxiv.org/abs/2503.16257)
  - 备注: 更偏 VideoLLM，但能帮助理解视频场景下 key/value 不同量化敏感性。

### 三、通用 LLM KV 量化方法
这部分是迁移对象。项目很大概率要先复现这里的思路，再判断哪些能迁到长视频生成。

- KIVI: A Tuning-Free Asymmetric 2bit Quantization for KV Cache
  - 论文链接: [arXiv:2402.02750](https://arxiv.org/abs/2402.02750)
  - 备注: 2-bit 非对称量化经典起点。
- Cache Me If You Must: Adaptive Key-Value Quantization for Large Language Models
  - 论文链接: [arXiv:2501.19392](https://arxiv.org/abs/2501.19392)
  - 备注: 自适应量化路线，适合拿来和固定 bit-width 对照。
- GEAR: An Efficient KV Cache Compression Recipe for Near-Lossless Generative Inference of LLM
  - 论文链接: [arXiv:2403.05527](https://arxiv.org/abs/2403.05527)
  - 备注: 更强调近无损压缩与生成保持。
- VQKV: High-Fidelity and High-Ratio Cache Compression via Vector-Quantization
  - 论文链接: [arXiv:2603.16435](https://arxiv.org/abs/2603.16435)
  - 备注: 向量量化路线，和视频时空冗余可能更契合。
- KVQuant: Towards 10 Million Context Length LLM Inference with KV Cache Quantization
  - 论文链接: [arXiv:2401.18079](https://arxiv.org/abs/2401.18079)
  - 备注: 更偏系统级与超长上下文极限压缩。

### 四、可辅助本项目的 KV 压缩 / 结构化记忆论文
这些论文不是量化，但非常适合变成“量化前的结构先验”。

- [[H2O✅]]
  - 作用: `heavy-hitter + recent` 思路，可帮助理解视频里的“关键历史 vs 最近历史”。
- [[SnapKV✅]]
  - 作用: token 选择与 observation window，适合做“先选择，再量化”的对照。
- [[PyramidKV✅]]
  - 作用: 分层预算分配，适合做 layer-wise mixed precision。
- [[Ada-KV✅]]
  - 作用: head-wise 自适应预算思想，适合拓展到 head-wise bit allocation。
- [[DuoAttention✅]]
  - 作用: retrieval heads / streaming heads 分工，适合考虑不同 head 使用不同量化精度。
- [[PQCache]]
  - 作用: 更偏“存储压缩”视角，可与视频量化路线对照。

## 当前项目判断
我对这条线的当前判断是：
- 只把 LLM 的 KV 量化原样搬到长视频生成，大概率能省显存，但不一定能保 motion dynamics；
- forcing 系列里最值得利用的结构先验，不是单纯的 layer/head，而是时间角色；
- 如果后面要做出有论文味道的方案，最自然的方向是“结构化记忆 + 角色感知量化”。

可以把它写成一个简单假设：
$$
b_{\text{sink}} \ge b_{\text{tail}} \ge b_{\text{history}}
$$
其中：
- `sink` 优先保长期 identity / scene anchor；
- `tail` 保最近运动连续性；
- `history` 作为中程结构信息，可以更激进压缩。
